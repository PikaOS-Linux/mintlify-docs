This page takes you from an empty directory to a tested release binary. It assumes you have [installed otr](/otr/installation).

## Run a program

Create `hello.otr`:

```otr
import std

pub fn main() void {
    std.io.println("Hello from otr")
}
```

Build and run it in one step:

```bash
otr run hello.otr
```

```text
Hello from otr
```

`otr run` builds in debug mode, which compiles fast and keeps every safety check. The build leaves a `.otr-cache` directory beside your file. It holds cached objects and check results, and you can delete it at any time.

## Read arguments

`main` can take an `Env`, which carries the command-line arguments, environment variables and the default I/O runtime. A `main` that can fail returns `!void`.

```otr
import std

pub fn main(env: std.Env) !void {
    name := if env.arg_count() > 1 { env.arg(1) } else { "world" }
    std.io.printf("Hello, {}!\n", .{ name })
}
```

Arguments after `--` go to your program:

```bash
otr run greet.otr -- Jade
```

```text
Hello, Jade!
```

`printf` takes a format string and a tuple of arguments. `{}` prints any value. Zig-style specifiers such as `{d:.2}`, `{x}` and `{s:<12}` work too.

## Handle errors and missing values

otr has no exceptions and no null pointers. A function that can fail returns an error union, and a value that may be absent is an optional.

```otr
import std

const ParseError = error { Empty, BadDigit }

fn parse(s: str) ParseError!u32 {
    if s.len == 0 { return error.Empty }
    var v: u32 = 0
    for c in s {
        if c < '0' or c > '9' { return error.BadDigit }
        v = v * 10 + (c - '0')
    }
    return v
}

fn find(xs: []i32, want: i32) ?usize {
    for x, i in xs {
        if x == want { return i }
    }
    return null
}

pub fn main() !void {
    arr := [4]i32{ 5, 7, 9, 11 }
    if find(&arr, 9) |i| {
        std.io.printf("found at {}\n", .{ i })
    }
    std.io.printf("{}\n", .{ find(&arr, 4) orelse 99 })

    a := try parse("21")
    b := parse("x1") catch 0
    std.io.printf("{} {}\n", .{ a, b })
}
```

```text
found at 2
99
21 0
```

`try` returns the error to the caller. `catch` supplies a fallback. `if value |x|` runs its block only when the optional holds a value, and `orelse` gives a default.

## Own a resource

A type with a `deinit` method is a resource. You must consume it on every path, and the compiler tells you when you forget.

```otr
import std
import std.list

pub fn main() void {
    var nums = list.List(i64).init(std.mem.heap)
    nums.push(1)
}
```

```text
bad_leak.otr:5:5: error: resource 'nums' is not consumed on every path (spec O3); add 'defer nums.deinit()'
```

Add the `defer` the diagnostic suggests:

```otr
var nums = list.List(i64).init(std.mem.heap)
defer nums.deinit()
nums.push(1)
```

`defer` runs its statement when the enclosing block exits, on every exit path. [Ownership and borrowing](/otr/memory/ownership-and-borrowing) covers the rules in full.

## Write a test

Tests are `test` blocks next to the code they check.

```otr
import std

fn add(a: i32, b: i32) i32 {
    return a + b
}

test "addition" {
    try std.testing.expect_equal(i32, 5, add(2, 3))
}

test "slices compare by contents" {
    try std.testing.expect_equal_slices(u8, "abc", "abc")
}
```

```bash
otr test t.otr
```

```text
test "addition" ... ok
test "slices compare by contents" ... ok
2 passed, 0 failed
```

## Check without building

`otr check` runs type and safety analysis and stops before code generation. It is the fastest way to find errors while you edit.

```bash
otr check hello.otr
```

## Build a release binary

```bash
otr build hello.otr -o hello --release
./hello
```

There are three build modes:

| Mode | Flag | Optimised | Integer overflow | Bounds checks |
| --- | --- | --- | --- | --- |
| debug | (none) | No | Panics | Kept |
| release | `--release` | Yes | Panics | Kept |
| release-fast | `--release-fast` | Yes | Wraps | Kept |

Bounds checks stay in every mode, so wrapping arithmetic in release-fast cannot break memory safety.

## Format your code

```bash
otr fmt hello.otr
otr fmt --check *.otr
```
