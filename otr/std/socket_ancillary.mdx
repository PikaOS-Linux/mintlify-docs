Caller-sized SCM_RIGHTS operations. No allocation and no implicit blocking.

```otr
import std.socket_ancillary
```

## control_words

```otr
fn control_words(fd_capacity: usize) linux.Error!usize
```

Each right separately padded, plus credentials and an inherited SO_PASSPIDFD.

## send

```otr
fn send(sock: &linux.Fd, bytes: []u8, fds: []i32, control: []mut u64) Error!usize
```

## receive

```otr
fn receive(sock: &linux.Fd, bytes: []out u8, fds: &mut list.List(linux.Fd), control: []mut u64) Error!Received
```

`fds` must already have capacity. Failure closes only this operation's rights.
