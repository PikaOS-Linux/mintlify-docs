Linux system calls with typed results: an owned file descriptor `Fd`, errors named
after errno, memory mappings, directory entries read with getdents64, and file
descriptors passed over Unix sockets. Every call costs what the C library call does
plus a compare of its result.

Descriptors made here are always close-on-exec; a child process gets one only
through `process.SpawnOptions.fds`.

```otr
import std.linux
```

## Example

```otr
import std
import std.linux

pub fn main() !void {
    // A pipe and an eventfd, the two usual ways to wake an event loop.
    pipe := try linux.pipe2(linux.O.nonblock)
    defer pipe.deinit()
    wake := try linux.eventfd(0, linux.EFD.nonblock)
    defer wake.deinit()

    // Each descriptor is registered with a datum that wait hands back.
    loop := try linux.Epoll.init()
    defer loop.deinit()
    try loop.add(&pipe.a, linux.EPOLL.readable, 1)
    try loop.add(&wake, linux.EPOLL.readable, 2)

    var events: [4]linux.EpollEvent
    std.io.printf("nothing ready yet: {}\n", .{ (try loop.wait(&out events, 0)).len == 0 })

    _ = try pipe.b.write("ping")
    try wake.write_u64(3)

    var buf: [16]u8
    var seen: u64 = 0
    for ev in try loop.wait(&out events, 0) {
        seen += ev.data()
    }
    // Sum of the two data, whatever order the kernel reported them in.
    std.io.printf("ready data sum: {}\n", .{ seen })
    std.io.printf("pipe: {}\n", .{ try pipe.a.read(&out buf) })
    std.io.printf("eventfd counter: {}\n", .{ try wake.read_u64() })

    try loop.remove(&wake)
    std.io.printf("after reading: {} ready\n", .{ (try loop.wait(&out events, 0)).len })
}
```

```text
nothing ready yet: true
ready data sum: 3
pipe: ping
eventfd counter: 3
after reading: 0 ready
```

## max_fds

```otr
const max_fds = 32
```

The default descriptor capacity for legacy send and receive calls.

## send_fds

```otr
fn send_fds(sock: &Fd, bytes: []u8, fds: []&Fd) Error!usize
```

Sends `bytes` (at least one) over the Unix socket `sock` with copies of the
descriptors `fds` (SCM_RIGHTS, at most `max_fds`); returns how many bytes went. The
descriptors stay open here.

## send_message

```otr
fn send_message(sock: &Fd, bytes: []u8, fds: anytype, nonblock: bool) Error!usize
```

`send_fds`, failing with `WouldBlock` instead of waiting when `nonblock` is set and the
socket's buffer is full. `fds` is a slice of `Fd` or of `&Fd`, so descriptors queued in
a list go without gathering references to them first.

## send_message_bounded

```otr
fn send_message_bounded(comptime capacity: usize, sock: &Fd, bytes: []u8, fds: anytype, nonblock: bool) Error!usize
```

Sends one SCM_RIGHTS message with stack storage for `capacity` descriptors, up to
Linux's limit of 253. A longer slice returns `Invalid` before sending anything.
Both `[]Fd` and `[]&Fd` are borrowed; sending never consumes or closes them.

## recv_fds

```otr
fn recv_fds(sock: &Fd, buf: []mut u8, fds: &mut list.List(Fd)) Error!usize
```

Receives up to `buf.len` bytes from the Unix socket `sock`, and appends the
descriptors sent with them to `fds`; returns how many bytes came, 0 once the peer
has closed its end.

## Fds

```otr
const Fds = bounded.BoundedList(Fd, max_fds)
```

The descriptors one `recv_message` can bring, in the order they were sent.

## recv_message

```otr
fn recv_message(sock: &Fd, buf: []out u8, fds: anytype, nonblock: bool) Error!Received
```

`recv_fds` into a buffer with no values yet, failing with `WouldBlock` instead of
waiting when `nonblock` is set and nothing has arrived. The descriptors are appended to
`fds`, a fixed-size queue so that receiving never allocates; any that do not fit are
closed, and reported as `truncated`.

## Ioctl

```otr
unsafe fn Ioctl(comptime dir: IoctlDir, comptime kind: u8, comptime nr: u8, comptime T: type) type
```

An ioctl taking a `T` the kernel reads (`write`), fills (`read`) or both: the request
number is built as the kernel's `_IOW`, `_IOR` and `_IOWR` macros build it, from `kind`,
`nr` and `T`'s size, and `call` is safe. Unsafe to declare: the kernel must touch only
the `T` given, so any pointer it holds as an integer must be one it would follow
anyway, which a safe wrapper around `call` makes sure of.
