Reading numbers from text, and formatting into fixed buffers.

```otr
import std.fmt
```

## Example

```otr
import std
import std.fmt

pub fn main() !void {
    port := try fmt.parse_int(u16, "8080", 10)
    mask := try fmt.parse_int(u32, "ff_ff", 16)
    auto := try fmt.parse_int(i64, "-0x10", 0)
    std.io.printf("{} {} {}\n", .{ port, mask, auto })

    ratio := try fmt.parse_float("2.5e-1")
    std.io.printf("{d}\n", .{ ratio })

    if fmt.parse_int(u8, "300", 10) |_| {} else |e| {
        std.io.printf("300 as u8: {}\n", .{ e })
    }
    if fmt.parse_int(i32, "12a", 10) |_| {} else |e| {
        std.io.printf("12a as i32: {}\n", .{ e })
    }

    // Formatting into a buffer on the stack: no allocation, null when it does not fit.
    var buf: [32]u8 = unsafe { undefined }
    if fmt.buf_print(&out buf, "{s}-{d:0>4}.log", .{ "bar", 17 }) |name| {
        std.io.println(name)
    }
    var tiny: [4]u8 = unsafe { undefined }
    std.io.printf("fits in 4 bytes: {}\n", .{ fmt.buf_print(&out tiny, "{}", .{ 123456 }) != null })

    std.io.printf("{} {} {}\n", .{ fmt.bytes(512), fmt.bytes(1536), fmt.bytes(20 * 1024 * 1024) })

    var raw: [4]u8 = unsafe { undefined }
    key := try fmt.hex_to_bytes(&out raw, "deadBEEF")
    std.io.printf("{} bytes, first {}\n", .{ key.len, key[0] })
}
```

```text

0.25
300 as u8: error.Overflow
12a as i32: error.InvalidCharacter
bar-0017.log
fits in 4 bytes: false
512 B 1.5 KiB 20.0 MiB
4 bytes, first 222
```

## ParseError

```otr
const ParseError = error { InvalidCharacter, Overflow }
```

## parse_int

```otr
fn parse_int(comptime T: type, s: str, base: u8) ParseError!T
```

The integer written in `s` in `base` (2 to 36), as Zig's `std.fmt.parseInt` reads it.
Base 0 reads a `0x`, `0o` or `0b` prefix and is decimal otherwise. A leading `+` or `-`
is allowed (`-0` for an unsigned type is 0; any other negative number overflows it), and
`_` may separate digits.

## parse_float

```otr
fn parse_float(s: str) ParseError!f64
```

The floating-point number written in `s`, in decimal or C hexadecimal notation, or
`inf`/`nan`, correctly rounded, whatever its length.

## parse_float32

```otr
fn parse_float32(s: str) ParseError!f32
```

`parse_float` for `f32`, rounded once from the decimal rather than through `f64`.

## buf_print

```otr
fn buf_print(out: []out u8, comptime fmt: []static u8, args: anytype) ?str
```

`fmt` formatted as `std.io.printf` does, written to the start of `out`, which need
not hold values yet; null when it does not fit.

## buf_print_z

```otr
fn buf_print_z(out: []out u8, comptime fmt: []static u8, args: anytype) ?[:0]u8
```

`buf_print` with a NUL after the text, for C (Zig's `bufPrintSentinel`): `out` needs
a byte to spare for it, and null is returned when the text and the NUL do not fit. A
NUL inside the text ends it for C.

## hex_to_bytes

```otr
fn hex_to_bytes(out: []out u8, hex: str) error { InvalidLength, NoSpaceLeft, InvalidCharacter }!str
```

The bytes that the hexadecimal pairs of `hex`, in either case, stand for, written to
the start of `out`, which need not hold values yet (Zig's `hexToBytes`).

## print_into

```otr
fn print_into(out: anytype, comptime fmt: []static u8, args: anytype) error { Full }!void
```

Appends `fmt` formatted as `std.io.printf` does to `out`, an `&mut InlineString(N)`
(std.bounded); `out` is unchanged when the result does not fit.

## bytes

```otr
fn bytes(n: u64) Bytes
```

`n` bytes for `{}` in `printf`: `512 B`, `1.5 KiB`, `20.0 MiB`, … up to TiB.
