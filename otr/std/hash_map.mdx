Hash maps that own their storage. `HashMap(K, V)` hashes integers, enums, bools and
static strings by value, and any other key type through its own
`hash(self: &Self) u64` and `eql(self: &Self, other: &Self) bool`; a key with neither,
a float among them, is a compile error. `StringMap(V)` owns
copies of its string keys and is looked up by `str`, since a borrowed `str` cannot be
stored (spec B8). `ArrayHashMap(K, V)` and `StringArrayHashMap(V)` keep their entries
in insertion order in dense arrays, for maps that are iterated more than probed.

Iterators borrow their map (spec R3): `iter` shares it and `iter_mut` holds it
exclusively, so the borrow checker rejects inserting or removing while one is in use
(B4, B5) and a table can never move under an iterator.

```otr
import std.hash_map
```

## Example

```otr
import std
import std.hash_map

pub fn main() void {
    heap := std.mem.heap

    // StringMap owns a copy of each key and is looked up by str.
    var stock = hash_map.StringMap(u32).init(heap)
    defer stock.deinit()
    _ = stock.put("apples", 4)
    _ = stock.put("pears", 9)
    old := stock.put("apples", 6) orelse 0
    std.io.printf("apples was {}, {} keys\n", .{ old, stock.len() })

    if stock.get("pears") |n| {
        std.io.printf("pears {}\n", .{ n.* })
    }
    if stock.get_mut("pears") |n| {
        n.* -= 1
    }
    _ = stock.remove("apples")
    std.io.printf("apples {} pears {}\n", .{ stock.contains("apples"), stock.get("pears").?.* })

    // HashMap takes integer, enum, bool and static string keys by value.
    var counts = hash_map.HashMap(u8, u32).init(heap)
    defer counts.deinit()
    for c in "mississippi" {
        counts.get_or_put_value(c, 0).value.* += 1
    }
    s: u8 = 's'
    p: u8 = 'p'
    z: u8 = 'z'
    std.io.printf("s {} p {} z {}\n", .{ counts.get(&s).?.*, counts.get(&p).?.*, counts.contains(&z) })

    // Iteration order is not defined, so only order-free results are printed.
    var total: u32 = 0
    var it = counts.iter()
    for e in it {
        total += e.value.*
    }
    std.io.printf("{} letters, {} distinct\n", .{ total, counts.len() })
}
```

```text
apples was 4, 2 keys
pears 9
apples false pears 8
s 4 p 2 z false
11 letters, 4 distinct
```

## hash_bytes

```otr
fn hash_bytes(bytes: []u8) u64
```

FNV-1a over `bytes`. Stable across versions, for keys written to disk; the tables
themselves hash with `hash_str`.

## hash_str

```otr
fn hash_str(bytes: []u8) u64
```

A fast 64-bit hash of `bytes` in the manner of wyhash: eight bytes per multiply, strings
of up to 16 bytes, most keys, without a loop, and longer ones in three independent
chains. Not stable across versions.

### HashMap.put

```otr

```

Stores `value` under `key` and returns the value it replaces. An equal key
already present stays; the new one is cleaned up if it is a resource.

### HashMap.put_with

```otr
fn put_with(self: &mut Self, key: K, fill: anytype) ?V
```

`put`, with the value `fill(out)` writes through `out`, which is the map's own
memory for it, so a large value is built in place rather than on the stack and
copied in. Returns the value `key` had.

### HashMap.get_or_put_value

```otr
fn get_or_put_value(self: &mut Self, key: K, value: V) GetOrPut(&K, V)
```

The entry for `key`, made with `value` when there is none; otherwise `key` and
`value` are cleaned up if they are resources. One probe, so counting is
`m.get_or_put_value(k, 0).value.* += 1`.

### HashMap.get_or_put_with

```otr
fn get_or_put_with(self: &mut Self, key: K, make: anytype) GetOrPut(&K, V)
```

The entry for `key`, made with the value `make()` returns when there is none, so
a costly value is built only on a miss; otherwise `key` is cleaned up if it is a
resource. One probe either way.

## ArrayHashMap

```otr
fn ArrayHashMap(comptime K: type, comptime V: type) type
```

A hash map that keeps its entries in insertion order, in dense arrays that iterate
as fast as a slice. Keys are hashed and compared as in `HashMap`. `swap_remove` is
O(1) and moves the last entry into the gap; `ordered_remove` keeps the order and
costs O(n).
