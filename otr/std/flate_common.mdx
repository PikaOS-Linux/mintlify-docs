## Alphabet

```otr
const Alphabet = enum
```

Canonical count/symbol representation reused from the whole-buffer inflater.
Under-subscribed trees are legal only for an unused distance alphabet or a single
length-1 literal/distance code. Code-length alphabets must be complete.

| Variant |
| --- |
| <code>literal</code> |
| <code>distance</code> |
| <code>code</code> |
