Ed25519 signatures (RFC 8032). Verification (§5.1.7) computes the point `[S]B - [k]A`
and compares its encoding with the signature's `R`, so a non-canonical `R` can never
match; `S` must be below the group order and `A` must decode canonically, which keeps
each signature to one accepted encoding. `KeyPair.from_seed` and `KeyPair.sign` make
keys and deterministic signatures (§5.1.5, §5.1.6) byte for byte as libsodium and Zig do.

Points are in extended coordinates over `field25519`, the radix-2^51 field `x25519`
uses; scalars are reduced mod the group order with `bigint`. Everything verification
checks is public, so its loop may branch on the scalars' bits. Signing multiplies the
base point by a secret with ref10's method, signed 4-bit digits over a table of
multiples built at compile time, where every entry of a row is read and the wanted one
kept through masks; its scalars go through `bigint`'s masked products. The expanded
secret key, the nonce and the digits are wiped before signing returns.

```otr
import std.crypto.ed25519
```

## Example

```otr
import std
import std.crypto.ed25519

pub fn main() !void {
    // Fixed bytes keep the output the same on every run; a real seed is 32 random
    // bytes that stay secret.
    seed := std.mem.array(32, u8, fn(i: usize) u8 { return @int_cast(u8, i + 1) })
    var keys = ed25519.KeyPair.from_seed(&seed)
    defer keys.wipe()

    message := "release 1.2.3 is genuine"
    sig := keys.sign(message)
    std.io.printf("public key {} bytes, signature {} bytes\n", .{ keys.public_key.len, sig.len })

    // Anyone holding the public key can check the signature.
    try ed25519.verify(&keys.public_key, message, &sig)
    std.io.println("signature accepted")

    if ed25519.verify(&keys.public_key, "release 6.6.6 is genuine", &sig) |_| {} else |err| {
        std.io.printf("changed message: {}\n", .{ err })
    }

    // Signing is deterministic: the same key and message give the same signature.
    again := keys.sign(message)
    std.io.printf("same signature again: {}\n", .{ std.mem.eql(u8, sig[0..], again[0..]) })
}
```

```text
public key 32 bytes, signature 64 bytes
signature accepted
changed message: error.InvalidSignature
same signature again: true
```

## KeyPair

```otr
const KeyPair = struct
```

A key pair from a 32-byte seed, the secret RFC 8032 calls the private key; libsodium's
and Zig's 64-byte secret key is the seed followed by `public_key`. Only `from_seed`
makes one, so the public key `sign` hashes always belongs to the seed: signing two
messages under a wrong public key would give away the secret scalar.

| Field | Type | Access |
| --- | --- | --- |
| <code>public_key</code> | <code>[32]u8</code> | Public |
| <code>seed</code> | <code>[32]u8</code> | Read-only |

### KeyPair.from_seed

```otr
fn from_seed(seed: &[32]u8) KeyPair
```

The key pair of `seed`, which should be 32 random bytes kept secret (§5.1.5).

### KeyPair.sign

```otr
fn sign(self: &KeyPair, msg: []u8) [64]u8
```

The signature of `msg` (§5.1.6): the nonce is a hash of the secret and the message,
so the same message always gets the same signature and no randomness is needed.

### KeyPair.wipe

```otr
fn wipe(self: &mut KeyPair) void
```

Clears the seed.

## verify

```otr
fn verify(public_key: &[32]u8, msg: []u8, sig: &[64]u8) Error!void
```

Checks the signature `sig` of `msg` under `public_key`.
