The server's identity in `std.tls`: the trust anchors, the certificate chain of a
Certificate message checked against them and the host name by `std.crypto.ca_bundle`,
and the handshake signatures made by the leaf's key, bound to what its certificate
allows that key and to the version's rules for signature schemes.

```otr
import std.tls.peer
```

## Trust

```otr
const Trust = union
```

Where the trust anchors come from: the system's roots, loaded once per process, or a
bundle of the caller's, which the client owns until `deinit`.

| Field | Type |
| --- | --- |
| <code>system</code> | <code>std.Env</code> |
| <code>roots</code> | <code>ca_bundle.Bundle</code> |

### Trust.deinit

```otr
fn deinit(self: Trust) void
```

## verify_chain

```otr
fn verify_chain(body: []u8, tls13: bool, trust: &Trust, host: []u8, now: i64) wire.Error!struct { usize, usize }
```

Where the leaf lies in the Certificate message `body`, after its chain is checked
against `trust` for `host` at `now`, seconds since the epoch.

## check_signature

```otr
fn check_signature(leaf: []u8, tls13: bool, suite: wire.Suite, scheme_id: u16, content: []u8, sig: []u8) wire.Error!void
```

Checks `sig`, made by the key of the certificate `leaf` with signature scheme
`scheme_id` over `content`; `suite` is the TLS 1.2 suite, which names the kind of key.

## certificate_verify

```otr
fn certificate_verify(body: []u8, leaf: []u8, suite: wire.Suite, pre: []u8) wire.Error!void
```

Checks the TLS 1.3 CertificateVerify `body`, the leaf's signature over the transcript
hash `pre` behind 64 spaces, the context string and a zero (RFC 8446 §4.4.3).

## key_exchange12

```otr
fn key_exchange12(body: []u8, leaf: []u8, suite: wire.Suite, client_random: &[32]u8, server_random: &[32]u8) wire.Error!struct { u16, usize, usize }
```

The group of the TLS 1.2 ServerKeyExchange `body` and where its key share lies in it,
once the leaf's signature over them and both randoms checks out. Only named curves
(RFC 8422 §5.4).
