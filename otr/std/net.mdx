TCP over IPv4 and IPv6, and Unix domain sockets. Listeners and connections are
resources: closing one is `deinit`. `connect` takes an address or a host name, which the
C library's resolver looks up as every other program on the system would (`/etc/hosts`,
nsswitch, systemd-resolved), giving IPv6 and IPv4 addresses in RFC 6724's order.
Calls block the calling task; on `Io.Threaded` other tasks keep running on other
threads (spec §10).

```otr
import std.net
```

## Example

```otr
import std
import std.net

// Answers one connection with what it was sent, in upper case.
fn shout_once(io: std.Io, listener: &net.Listener) net.Error!void {
    conn := try listener.accept(io)
    defer conn.deinit()
    var buf: [64]u8
    got := try conn.read(io, &out buf)
    for mut b in got {
        if b.* >= 'a' and b.* <= 'z' { b.* -= 32 }
    }
    try conn.write_all(io, got)
}

pub fn main(env: std.Env) !void {
    io := env.io

    // Port 0 asks the kernel for a free port; listener.port() tells which.
    listener := try net.listen(io, .{ host: "127.0.0.1" })
    defer listener.deinit()
    server := io.async(fn[io, &listener]() net.Error!void { return shout_once(io, &listener) })
    // If the client fails, cancelling ends the server's wait in accept.
    defer server.cancel(io) catch {}

    conn := try net.connect(io, "127.0.0.1", listener.port())
    defer conn.deinit()
    try conn.write_all(io, "hello over tcp")

    var buf: [64]u8
    reply := try conn.read(io, &out buf)
    std.io.printf("reply: {}\n", .{ reply })

    // The server closed its end, so the next read is empty.
    rest := try conn.read(io, &out buf)
    std.io.printf("after close: {} bytes\n", .{ rest.len })
}
```

```text
reply: HELLO OVER TCP
after close: 0 bytes
```

## Conn

```otr
const Conn = struct
```

| Field | Type | Access |
| --- | --- | --- |
| <code>fd</code> | <code>i32</code> | Read-only |

### Conn.read

```otr
fn read(self: &Conn, io: std.Io, buf: []out u8) Error! []mut u8
```

Reads up to `buf.len` bytes into `buf`, which need not hold values yet, and returns
the part it filled; that is empty when the peer closed the connection.

### Conn.read_exact

```otr
fn read_exact(self: &Conn, io: std.Io, buf: []mut u8) Error!void
```

Fills all of `buf`; the peer closing the connection first is `EndOfStream`.

### Conn.write_all

```otr
fn write_all(self: &Conn, io: std.Io, data: str) Error!void
```

Writes all of `data`.

### Conn.try_read

```otr
fn try_read(self: &Conn, buf: []out u8) Error!?[]mut u8
```

`read` that never waits, for a socket from `connect_start`: null when nothing has
arrived yet, and an empty slice when the peer closed the connection.

### Conn.try_write

```otr
fn try_write(self: &Conn, data: str) Error!usize
```

Writes what the socket takes now of `data`, which is not empty, without waiting;
0 when its send buffer is full.

### Conn.connect_status

```otr
fn connect_status(self: &Conn) Error!void
```

Once a socket from `connect_start` is writable, whether its connection was made:
the kernel keeps the outcome of a non-blocking connect in SO_ERROR.

### Conn.set_no_delay

```otr
fn set_no_delay(self: &Conn, on: bool) Error!void
```

Turns Nagle's algorithm off (TCP_NODELAY), so each write goes out at once instead of
waiting for the peer to acknowledge the one before. A protocol that writes a request
in several pieces, as TLS does a record at a time, otherwise waits out the peer's
delayed acknowledgement, 40 ms on Linux, between them.

### Conn.poll_fd

```otr
fn poll_fd(self: &Conn) i32
```

Ready when there is something to read, for `Io.select`.

### Conn.into_fd

```otr
fn into_fd(self: Conn) linux.Fd
```

Transfers ownership to the shared socket queue, without duplicating the socket.

### Conn.close

```otr
fn close(self: Conn) void
```

Closes the socket; the same as `deinit`.

### Conn.deinit

```otr
fn deinit(self: Conn) void
```

## connect

```otr
fn connect(io: std.Io, host: str, port: u16) Error!Conn
```

Connects to `port` on `host`, an IPv4 or IPv6 address or a host name, trying each
address `resolve` gives in its order until one accepts.

## resolve

```otr
fn resolve(io: std.Io, host: str, port: u16) Error!bounded.BoundedList(Address, max_addresses)
```

The addresses of `host`, an IPv4 or IPv6 address or a host name, in the resolver's
order, with `port`. The lookup blocks the calling task (the C library's resolver
waits on the network), so an event loop runs it before or beside its loop.

## numeric

```otr
fn numeric(host: str, port: u16) Error!bounded.BoundedList(Address, max_addresses)
```

`host` with `port` when `host` is an IPv4 or IPv6 address, found without the resolver;
`InvalidAddress` for a name.

## Lookup

```otr
const Lookup = struct
```

A host name looked up without blocking the caller: the C library's resolver, which
follows nsswitch as `resolve` does, runs on a thread of its own, and `poll_fd` turns
readable when its answer is in, for an event loop to wait on. Dropping a `Lookup`
before then is safe: the thread holds its own handle to the answer's channel.

| Field | Type | Access |
| --- | --- | --- |
| <code>answer</code> | <code>sync.Channel(Found)</code> | Read-only |

### Lookup.start


### Lookup.deinit

```otr
fn deinit(self: Lookup) void
```

### Lookup.poll_fd

```otr
fn poll_fd(self: &Lookup) i32
```

Readable once the answer is in.

### Lookup.take

```otr
fn take(self: &mut Lookup) ?Found
```

The answer, once it is in; null before.

## connect_start

```otr
fn connect_start(addr: Address) Error!Conn
```

Starts connecting to `addr` without waiting: the socket is non-blocking, so it is
read and written with `Conn.try_read` and `Conn.try_write`, and once it is writable
`Conn.connect_status` tells whether the connection was made. For event loops, and for
connects with a time limit.

## connect_unix_start

```otr
fn connect_unix_start(name: str, abstract: bool) Error!Conn
```

Starts a nonblocking Unix connection using the exact pathname or abstract length.
An abstract `name` excludes the leading NUL; embedded NULs remain part of its name.

## listen_unix

```otr
fn listen_unix(io: std.Io, path: str) Error!Listener
```

Listens on a Unix domain socket created at `path`, which must not exist yet;
closing the listener leaves the file behind for the caller to delete.

## connect_unix

```otr
fn connect_unix(io: std.Io, path: str) Error!Conn
```

Connects to the Unix domain socket at `path`.
