Sets of small integers as bits in 64-bit words. `StaticBitSet(N)` is a value holding
`N` bits inline; `DynamicBitSet` owns a heap buffer whose length is chosen at run time.
Both answer every query a word at a time: counting is a population count per word, and
iterating the set bits clears the lowest one per step (`w & (w - 1)`), so neither
branches per bit. Bits past the length are always clear, so whole-word operations
need no masking afterwards.

```otr
import std.bitset
```

## Example

```otr
import std
import std.bitset

pub fn main() void {
    // StaticBitSet holds its bits inline and needs no allocator.
    var seen = bitset.StaticBitSet(64).init_empty()
    seen.set(3)
    seen.set(17)
    seen.set(40)
    seen.toggle(17)
    seen.set_range_value(8, 12, true)
    std.io.printf("count {} bit 3 {} bit 17 {}\n", .{ seen.count(), seen.is_set(3), seen.is_set(17) })

    var it = seen.iter()
    for i in it {
        std.io.printf("{} ", .{ i })
    }
    std.io.println("")

    var mask = bitset.StaticBitSet(64).init_empty()
    mask.set_range_value(0, 10, true)
    seen.intersect_with(&mask)
    std.io.printf("below 10: {}, lowest {}\n", .{ seen.count(), seen.find_first_set() orelse 0 })

    // DynamicBitSet takes its length at run time and owns heap storage.
    var free = bitset.DynamicBitSet.init_full(std.mem.heap, 100)
    defer free.deinit()
    free.unset(0)
    free.unset(1)
    std.io.printf("{} of {} free, first free {}\n", .{ free.count(), free.len(), free.find_first_set() orelse 0 })
}
```

```text
count 6 bit 3 true bit 17 false
3 8 9 10 11 40 
below 10: 3, lowest 3
98 of 100 free, first free 2
```

## pop_count

```otr
fn pop_count(x: u64) u64
```

The number of set bits in `x`. The classic bit-slicing sum, which the optimiser turns
into one `popcnt` instruction on every target otr supports.

## trailing_zeros

```otr
fn trailing_zeros(x: u64) u64
```

The number of zero bits below the lowest set bit of `x`; 64 when `x` is 0. Written as
the population count of the bits below it, which the optimiser turns into `tzcnt`.

## SetBits

```otr
const SetBits = ref struct
```
