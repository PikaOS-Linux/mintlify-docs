Civil dates and times in the proleptic Gregorian calendar, and `strftime`/`strptime`
formatting and parsing of them into caller buffers, without allocating. A `DateTime`
is one instant seen at one UTC offset; `std.tz` finds the offset a time zone has at
an instant. The day arithmetic is Neri and Schneider's (2021): no branches, no tables,
a few multiplications.

```otr
import std.datetime
```

## Example

```otr
import std
import std.datetime

pub fn main() !void {
    // A fixed instant, seen first at UTC and then at UTC+1.
    utc := datetime.DateTime.from_unix(1790000000, datetime.Offset.utc())
    std.io.printf("{}\n", .{ utc })
    std.io.printf("{} {} {}, {}:{d:0>2}\n", .{ datetime.weekday_name(utc.weekday), utc.day, datetime.month_name(utc.month), utc.hour, utc.minute })

    cet := utc.to_offset(datetime.Offset.fixed(3600, "CET"))
    std.io.printf("{} (same instant: {})\n", .{ cet, cet.unix() == utc.unix() })

    var buf: [64]u8 = unsafe { undefined }
    if cet.strftime(&mut buf, "%A %d %B %Y, %H:%M %Z (week %V)") |text| {
        std.io.println(text)
    }

    parsed := try datetime.strptime("2026-02-28 23:30:00 +0100", "%Y-%m-%d %H:%M:%S %z")
    std.io.printf("parsed {} = {} unix\n", .{ parsed, parsed.unix() })

    built := try datetime.DateTime.civil(2024, 2, 29, 12, 0, 0, datetime.Offset.utc())
    std.io.printf("leap day {}, day {} of the year\n", .{ built, built.yday })
    if datetime.DateTime.civil(2026, 2, 30, 0, 0, 0, datetime.Offset.utc()) |_| {} else |e| {
        std.io.printf("February 30: {}\n", .{ e })
    }

    // Plain calendar arithmetic works in days since 1970-01-01.
    days := datetime.days_from_civil(2026, 12, 25) - datetime.days_from_civil(2026, 11, 11)
    week := datetime.iso_week(2027, 1, 1)
    std.io.printf("{} days apart, 2028 leap: {}, February 2026 has {} days\n", .{ days, datetime.is_leap_year(2028), datetime.days_in_month(2026, 2) })
    std.io.printf("2027-01-01 is in ISO week {} of {}\n", .{ week.week, week.year })
}
```

```text
2026-09-21T14:13:20Z
Monday 21 September, 14:13
2026-09-21T15:13:20+01:00 (same instant: true)
Monday 21 September 2026, 15:13 CET (week 39)
parsed 2026-02-28T23:30:00+01:00 = 1772317800 unix
leap day 2024-02-29T12:00:00Z, day 60 of the year
February 30: error.OutOfRange
44 days apart, 2028 leap: true, February 2026 has 28 days
2027-01-01 is in ISO week 53 of 2026
```

### DateTime.strftime

```otr
fn strftime(self: &DateTime, out: []mut u8, spec: str) ?str
```

The text `spec` describes, written to the start of `out`; null when it does not
fit. Conversions follow glibc's `strftime` in the C locale: `%a %A %b %B %c %C %d
%D %e %F %g %G %h %H %I %j %k %l %m %M %n %p %P %r %R %s %S %t %T %u %U %V %w %W %x
%X %y %Y %z %Z %%`, with GNU's flags (`-` no padding, `_` spaces, `0` zeros, `^`
upper case, `#` upper case names and lower case `%p`), a field width, and the
ignored `E`/`O` modifiers. Two extensions: `%:z` (`+01:00`) and `%f`
(microseconds, six digits). Any other conversion is copied as written.

### DateTime.format

```otr
fn format(self: DateTime, w: anytype) void
```

RFC 3339 for `{}` in `printf`: `2026-10-18T09:05:00+01:00`, or `...Z` at UTC.

## strptime

```otr
fn strptime(text: str, spec: str) ParseError!DateTime
```

The date and time `text` gives in the layout `spec`, read as glibc's `strptime` reads
it in the C locale. White space in `spec` matches any run of it, possibly empty;
numbers may be preceded by spaces; names match in any case, in full or by their first
three letters. Fields not given default to 1970-01-01 00:00:00 UTC. The offset comes
from `%z` (`Z`, `+hh`, `+hhmm` or `+hh:mm`, and no other count of digits), with
`%Z`'s name kept as its abbreviation, and `%s` gives the instant itself, which is
`OutOfRange` when its year on that offset's wall clock does not fit an `i32`. `%f`
reads up to nine digits of a fraction of a second. `%y` alone is 1969 to 2068, as POSIX has it; with `%C` it is the year in that
century. `%j` sets the month and day when neither is given. Weekdays and week numbers
(`%a %A %u %w %U %W %V %G %g`) are read and checked to be well formed but do not set
the date. All of `text` must be used.
