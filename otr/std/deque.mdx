A double-ended queue that owns its elements: a ring buffer whose capacity is a power
of two, so an index wraps with a mask. Pushing and popping at either end is O(1)
amortised, and growing keeps the elements where they are when they do not wrap.

```otr
import std.deque
```

## Example

```otr
import std
import std.deque

pub fn main() void {
    var jobs = deque.Deque(i64).init(std.mem.heap)
    defer jobs.deinit()

    jobs.push_back(2)
    jobs.push_back(3)
    jobs.push_front(1)
    jobs.push_front(0)
    std.io.printf("len {} front {} back {}\n", .{ jobs.len(), jobs.front().?.*, jobs.back().?.* })

    if jobs.get_mut(1) |job| {
        job.* = 10
    }

    var it = jobs.iter()
    for job in it {
        std.io.printf("{} ", .{ job.* })
    }
    std.io.println("")

    // Take from the front as a queue, from the back as a stack.
    first := jobs.pop_front() orelse -1
    last := jobs.pop_back() orelse -1
    std.io.printf("popped {} and {}, {} left\n", .{ first, last, jobs.len() })

    for {
        job := jobs.pop_front() orelse break
        std.io.printf("ran {}\n", .{ job })
    }
    std.io.printf("empty {}\n", .{ jobs.pop_front() == null })
}
```

```text
len 4 front 0 back 3
0 10 2 3 
popped 0 and 3, 2 left
ran 10
ran 2
empty true
```

## Slices


The elements of a deque in order, as the two pieces of the ring they occupy; `second`
is empty unless the elements wrap.
