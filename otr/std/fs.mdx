Files and directories, and watching them for changes.

```otr
import std.fs
```

## Example

```otr
import std
import std.fs
import std.path

pub fn main() !void {
    heap := std.mem.heap

    dir := path.join(heap, fs.temp_dir(), "otr-example-fs")
    defer dir.deinit()
    try fs.make_path(heap, dir.as_str())

    draft := path.join(heap, dir.as_str(), "draft.txt")
    defer draft.deinit()
    notes := path.join(heap, dir.as_str(), "notes.txt")
    defer notes.deinit()

    try fs.write_file(heap, draft.as_str(), "line one\nline two\n")
    try fs.rename(heap, draft.as_str(), notes.as_str())

    text := try fs.read_file(heap, notes.as_str())
    defer text.deinit()
    info := try fs.stat(heap, notes.as_str())
    std.io.printf("notes.txt: {} bytes\n{}", .{ info.size, text.as_str() })
    std.io.printf("draft.txt exists: {}\n", .{ fs.exists(heap, draft.as_str()) })

    entries := try fs.list_dir(heap, dir.as_str())
    defer entries.deinit()
    for e in entries.items() {
        std.io.printf("{} ({})\n", .{ e.name.as_str(), @tag_name(e.kind) })
    }

    if fs.read_file(heap, draft.as_str()) |gone| {
        gone.deinit()
    } else |err| {
        std.io.printf("reading draft.txt: {}\n", .{ err })
    }

    try fs.delete_file(heap, notes.as_str())
    try fs.delete_dir(heap, dir.as_str())
}
```

```text
notes.txt: 18 bytes
line one
line two
draft.txt exists: false
notes.txt (file)
reading draft.txt: error.NotFound
```

## Error

## read_file


The contents of the file at `path`.

## write_file

```otr
fn write_file(alloc: mem.Allocator, path: str, data: str) Error!void
```

Replaces the file at `path` with `data`, creating it if needed with mode 0o666 less the
umask, as open(2) and Zig's `createFile` do.

## Change

### Change.overflow


### Change.ignored

```otr
const ignored: u32 = 0x8000
```

The watch is gone: removed, or its file deleted.

### Change.is_dir


### Watcher.init

```otr
fn init() Error!Watcher
```

### Watcher.add

```otr
fn add(self: &mut Watcher, path: str, mask: u32) Error!Wd
```

Starts reporting the `Change` bits in `mask` for `path`; a path watched already
is `AlreadyExists`.

### Watcher.remove

```otr
fn remove(self: &mut Watcher, wd: Wd) void
```

Stops a watch; `next` reports it once more, with `Change.ignored`.

### Watcher.next

```otr
fn next(self: &mut Watcher, io: std.Io) std.Io.Canceled!?Event
```

Waits for the next change; null once no watch is left.

### Watcher.poll

```otr
fn poll(self: &mut Watcher) ?Event
```

The next change already waiting, without waiting for one: null when there is none,
as after a loop found `poll_fd` readable and took them all.

### Watcher.poll_fd

```otr
fn poll_fd(self: &Watcher) i32
```

Ready when a change is waiting, for `Io.select`.

```otr

```

## write_file_durable

```otr
fn write_file_durable(alloc: mem.Allocator, path: str, data: str) Error!void
```

`write_file_atomic` that also survives a crash or power loss: the temporary file's data
reaches the disk before the rename, and the rename before it returns, so after a crash
`path` holds the old contents or the new, never an empty or partial file. Each call
waits for the disk, so it is for configuration and state, not caches. The file gets mode
0o666 less the umask, as `write_file`; `write_file_durable_mode` takes another.

## write_file_durable_mode

```otr
fn write_file_durable_mode(alloc: mem.Allocator, path: str, data: str, mode: u32) Error!void
```

`write_file_durable` with `mode` (less the umask) for the file, such as 0o600 for one
only its owner may read. The file is replaced by a rename, so the mode holds even when
`path` existed with another.

## write_file_atomic

```otr
fn write_file_atomic(alloc: mem.Allocator, path: str, data: str) Error!void
```

Replaces the file at `path` with `data` so that readers see the old contents or the
new, never a mix: the data goes to a temporary file beside it, which is then renamed
over `path`. It does not wait for the data to reach the disk.

## temp_dir

```otr
fn temp_dir() []static u8
```

The directory for temporary files: `TMPDIR`, else `/tmp`. `otr test` and otr's test
harness give each run a fresh one of its own.

## real_path

```otr
fn real_path(alloc: mem.Allocator, path: str) Error!string.String
```

The absolute path `path` names with every symbolic link, `.` and `..` resolved
(realpath(3)); the file must exist. Comparing it with `path` tells whether `path` was
already canonical, as a privileged helper checks a path it is given.
