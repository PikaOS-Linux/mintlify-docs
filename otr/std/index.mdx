Each page lists a module's public declarations with their signatures and doc comments, as `otr doc` prints them. For a guided tour with longer examples, read the [standard library guide](/otr/standard-library).

Reach a module as `std.<name>` after `import std`, or import it on its own with `import std.<name>`.

## Core

| Module | Purpose |
| --- | --- |
| [`std`](/otr/std/std) | The otr standard library. |
| [`std.runtime`](/otr/std/runtime) | The program environment and the default Io runtime (spec §10). |
| [`std.io`](/otr/std/io) | Writing to standard output and standard error, formatting into anything with a write_all(self: &mut Self, s: str) void method, such as String, and reading standard input line by line. |
| [`std.fmt`](/otr/std/fmt) | Reading numbers from text, and formatting into fixed buffers. |
| [`std.log`](/otr/std/log) | Messages for whoever runs the program, on standard error, each marked with its level. |
| [`std.debug`](/otr/std/debug) | Checks for conditions the program relies on. |
| [`std.testing`](/otr/std/testing) | Assertions for test blocks. |
| [`std.testing_allocator`](/otr/std/testing_allocator) | Instance-local allocation fault injection. |

## Cryptography

| Module | Purpose |
| --- | --- |
| [`std.crypto`](/otr/std/crypto) | Building blocks for code that handles secrets. |
| [`std.crypto.sha2`](/otr/std/crypto/sha2) | SHA-2 (FIPS 180-4). |
| [`std.crypto.md5`](/otr/std/crypto/md5) | MD5 (RFC 1321), 16-byte digests, for the legacy protocols that still name it, such as NTLMv2's HMAC-MD5. |
| [`std.crypto.hmac`](/otr/std/crypto/hmac) | HMAC (RFC 2104, FIPS 198-1) over any hasher with init, update, final, digest_len and block_len, such as sha2.Sha256, or hash.Sha1 and md5.Md5 for the legacy protocols that name them (HMAC-SHA1, NTLMv2's HMAC-MD5). |
| [`std.crypto.hkdf`](/otr/std/crypto/hkdf) | HKDF (RFC 5869), the key derivation of TLS 1.3. |
| [`std.crypto.aes`](/otr/std/crypto/aes) | The AES block cipher (FIPS-197) with 128- and 256-bit keys, encryption only, and CTR mode with a 32-bit big-endian counter in the last four bytes of the counter block (NIST SP 800-38A, as GCM, CCM and SMB 3 count). |
| [`std.crypto.aes_gcm`](/otr/std/crypto/aes_gcm) | AES-128-GCM and AES-256-GCM (NIST SP 800-38D) with 12-byte nonces and 16-byte tags, the AEADs of TLS 1.3 and QUIC. |
| [`std.crypto.aes_ccm`](/otr/std/crypto/aes_ccm) | AES-CCM (NIST SP 800-38C, RFC 3610). |
| [`std.crypto.aes_cmac`](/otr/std/crypto/aes_cmac) | AES-CMAC (RFC 4493, NIST SP 800-38B), the MAC of SMB 3 signing, with a 16- or 32-byte key and a 16-byte MAC. |
| [`std.crypto.chacha20poly1305`](/otr/std/crypto/chacha20poly1305) | ChaCha20-Poly1305 (RFC 8439), the AEAD of TLS 1.3, WireGuard and SSH. |
| [`std.crypto.x25519`](/otr/std/crypto/x25519) | X25519 (RFC 7748). |
| [`std.crypto.ed25519`](/otr/std/crypto/ed25519) | Ed25519 signatures (RFC 8032). |
| [`std.crypto.field25519`](/otr/std/crypto/field25519) | Arithmetic modulo p = 2^255 - 19, the field of Curve25519 and edwards25519, shared by x25519 and ed25519. |
| [`std.crypto.ecc`](/otr/std/crypto/ecc) | The NIST prime curves P-256 and P-384 (FIPS 186-5, SEC 2), for checking ECDSA signatures and for ECDH key exchange (TLS's secp256r1 and secp384r1 groups). |
| [`std.crypto.ecdsa`](/otr/std/crypto/ecdsa) | ECDSA signature verification (FIPS 186-5) over P-256 and P-384, as TLS and X.509 use it. |
| [`std.crypto.rsa`](/otr/std/crypto/rsa) | RSA signature verification (RFC 8017). |
| [`std.crypto.bigint`](/otr/std/crypto/bigint) | Arithmetic modulo an odd number of up to 64 * N bits, for checking signatures. |
| [`std.crypto.asn1`](/otr/std/crypto/asn1) | A reader for DER (X.690), the encoding of certificates, keys and ECDSA signatures. |
| [`std.crypto.x509`](/otr/std/crypto/x509) | X.509 v3 certificates (RFC 5280). |
| [`std.crypto.ca_bundle`](/otr/std/crypto/ca_bundle) | Trust anchors and certificate chain verification. |
| [`std.crypto.hostname`](/otr/std/crypto/hostname) | Host name and IP address matching for certificates (RFC 6125). |
