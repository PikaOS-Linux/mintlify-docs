Region allocators (spec §7.5): memory that is freed all at once when the region ends.

```otr
import std.arena
```

## Example

```otr
import std
import std.arena

fn Node(comptime r: region) type {
    return struct {
        value: i64
        next: ?&r Node(r)
    }
}

pub fn main() void {
    // Everything allocated from the region is freed together when it ends.
    region r = arena.Arena.init(std.mem.heap)
    defer r.deinit()

    var head: ?&r Node(r) = null
    for i in 0..5 {
        head = r.new(Node(r){ value: @int_cast(i64, i), next: head })
    }
    var sum: i64 = 0
    var it = head
    for it != null {
        node := it.?
        sum += node.value
        it = node.next
    }
    std.io.printf("linked sum {}\n", .{ sum })

    // Region collections have no deinit of their own.
    squares := r.list(i64)
    for i in 1..5 {
        squares.push(@int_cast(i64, i * i))
    }
    names := r.map(u32, []static u8)
    names.put(7, "seven")
    text := r.string()
    text.push_str("in a region")
    zeros := r.alloc(u8, 16, 0)

    std.io.printf("{} squares, last {}\n", .{ squares.len(), squares.at(3) })
    std.io.printf("{} {} {}\n", .{ names.get(7) orelse "?", text.as_str(), zeros.len })
}
```

```text
linked sum 10
4 squares, last 16
seven in a region 16
```

## Arena

```otr
const Arena = struct
```

Bump allocation in chunks. Each chunk starts with a header holding the previous
chunk and the chunk's size, so `deinit` can free them all.

| Field | Type | Access |
| --- | --- | --- |
| <code>alloc</code> | <code>mem.Allocator</code> | Read-only |
| <code>chunk</code> | <code>?[*]u8</code> | Read-only |
| <code>used</code> | <code>usize</code> | Read-only |
| <code>cap</code> | <code>usize</code> | Read-only |

### Arena.init

```otr
fn init(alloc: mem.Allocator) Arena
```

### Arena.deinit

```otr
fn deinit(self: Arena) void
```

### Arena.reset

```otr
fn reset(self: &mut Arena, mode: ResetMode) bool
```

Invalidates previous raw allocations and preheats one retained chunk. False means
preheating failed; the arena remains usable with its last chunk. Region allocators
are hidden behind the compiler's region lifetime boundary.

### Arena.alloc_raw

```otr
fn alloc_raw(self: &mut Arena, size: usize, alignment: usize) [*]u8
```

`size` bytes aligned to `alignment` (a power of two), valid until the region ends.

### Arena.try_alloc_raw

```otr
fn try_alloc_raw(self: &mut Arena, size: usize, alignment: usize) error { NoMemory, Overflow, InvalidAlignment }! [*]u8
```

Failure leaves earlier allocations and the bump cursor intact. Padding is based
on the absolute address, since a chunk need not share the requested alignment.

## FixedBuffer

## Stack

```otr
const Stack = struct
```

A reserved address range that region frames are carved from in LIFO order: a second
stack for data whose size is only known at run time. `reserve` maps address space
only; pages become resident as frames touch them, and a frame that ends more than
`keep` bytes above its start returns the excess to the system, so one large frame
does not pin its peak for the rest of the program. A `Stack` is owned by one thread
or task, so frames from different tasks never interleave on it.

| Field | Type | Access | Description |
| --- | --- | --- | --- |
| <code>base</code> | <code>[*]u8</code> | Read-only |  |
| <code>cap</code> | <code>usize</code> | Read-only |  |
| <code>top</code> | <code>usize</code> | Read-only |  |
| <code>keep</code> | <code>usize</code> | Read-only |  |
| <code>live</code> | <code>u64</code> | Read-only | The frame allowed to allocate, and the last id handed out; 0 is no frame. |
| <code>last</code> | <code>u64</code> | Read-only |  |

### Stack.reserve

```otr
fn reserve(bytes: usize) error { NoMemory }!Stack
```

Reserves `bytes` of address space (rounded up to whole pages) without committing it.

### Stack.deinit

```otr
fn deinit(self: Stack) void
```

### Stack.set_keep

```otr
fn set_keep(self: &mut Stack, bytes: usize) void
```

Bytes a frame may leave resident above its start when it ends.

### Stack.used

```otr
fn used(self: &Stack) usize
```

Bytes currently allocated by live frames.

### Stack.frame

```otr
fn frame(self: &mut Stack) Frame
```

The outermost frame: `region r = stack.frame()`.

## Frame

```otr
const Frame = ref struct
```

A region allocator over the top of a `Stack`. It borrows the stack, so while a frame is
live no other code can open one from the stack; `r.frame()` opens a nested frame
(spec G11). Allocation is a bump of the stack's top and the end of the region pops it.

| Field | Type | Access |
| --- | --- | --- |
| <code>stack</code> | <code>&amp;mut Stack</code> | Read-only |
| <code>mark</code> | <code>usize</code> | Read-only |
| <code>id</code> | <code>u64</code> | Read-only |
| <code>parent</code> | <code>u64</code> | Read-only |

### Frame.deinit

```otr
fn deinit(self: Frame) void
```

### Frame.frame

```otr
fn frame(self: &mut Frame) Frame
```

A frame above this one, ending before it (`r.frame()`).

### Frame.alloc_raw


## RList

```otr

```

| Field | Type | Access | Description |
| --- | --- | --- | --- |
| <code>arena</code> | <code>[*]u8</code> | Read-only | The region's allocator, untyped: it may borrow, which a field cannot (B8), and G4 keeps the collection inside the region's block anyway. |
| <code>ptr</code> | <code>?[*]T</code> | Read-only |  |
| <code>count</code> | <code>usize</code> | Read-only |  |
| <code>cap</code> | <code>usize</code> | Read-only |  |

### RMap.iter

```otr
fn iter(self: &r Self) RMapIter(r, K, V)
```

The entries, as copies, in no particular order. The iterator reads the buffers
the map had when it began, which a growth leaves in place (G10), so a `put`
while it runs is safe: it yields each entry present at the start once, and
may or may not yield ones added meanwhile.
