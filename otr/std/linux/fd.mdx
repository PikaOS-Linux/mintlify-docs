Owned Linux descriptors and errno-typed calls.

```otr
import std.linux.fd
```

## Example

```otr
import std
import std.fs
import std.linux.fd
import std.path

pub fn main() !void {
    heap := std.mem.heap
    dir := path.join(heap, fs.temp_dir(), "otr-example-linux-fd")
    defer dir.deinit()
    try fs.make_path(heap, dir.as_str())
    name := path.join(heap, dir.as_str(), "lines.txt")
    defer name.deinit()

    // An Fd is a resource: deinit closes it.
    {
        out := try fd.open(name.as_str(), fd.O.wronly | fd.O.creat | fd.O.trunc, 0o600)
        defer out.deinit()
        n := try out.write("first line\nsecond line\n")
        std.io.printf("wrote {} bytes\n", .{ n })
    }

    file := try fd.open(name.as_str(), fd.O.rdonly, 0)
    defer file.deinit()
    var first: [10]u8
    var buf: [64]u8
    // read and pread return the part of the buffer they filled.
    std.io.printf("read: {}\n", .{ try file.read(&out first) })
    std.io.printf("pread at 11: {}", .{ try file.pread(&out buf, 11) })
    std.io.printf("at end of file: {} bytes\n", .{ (try file.pread(&out buf, 23)).len })

    // A pipe: a is the read end, b the write end.
    pipe := try fd.pipe2(0)
    defer pipe.deinit()
    _ = try pipe.b.write("through a pipe")
    std.io.printf("pipe: {}\n", .{ try pipe.a.read(&out buf) })

    try fd.unlink(name.as_str())
    try fs.delete_dir(heap, dir.as_str())
    if fd.open(name.as_str(), fd.O.rdonly, 0) |f| {
        f.deinit()
    } else |err| {
        std.io.printf("after unlink: {}\n", .{ err })
    }
}
```

```text
wrote 23 bytes
read: first line
pread at 11: second line
at end of file: 0 bytes
pipe: through a pipe
after unlink: error.NotFound
```

## Fd

```otr
const Fd = struct
```

An open file descriptor, closed by `deinit`. Only this module and `from_raw` make
one, so each descriptor has one owner and is closed once.

| Field | Type | Access |
| --- | --- | --- |
| <code>fd</code> | <code>i32</code> | Read-only |

### Fd.from_raw

```otr
unsafe fn from_raw(fd: i32) Fd
```

Takes ownership of descriptor `fd`. Unsafe: nothing else may close it or wrap it
again, or a later `deinit` closes a descriptor that another part of the program
has been given since.

### Fd.raw

```otr
fn raw(self: &Fd) i32
```

The descriptor's number, for C calls and `Io.wait_readable`; it stays owned here.

### Fd.into_raw

```otr
fn into_raw(self: Fd) i32
```

Gives up ownership without closing; the caller closes the number.

### Fd.poll_fd

```otr
fn poll_fd(self: &Fd) i32
```

Ready to read, for `Io.select`.

### Fd.dup

```otr
fn dup(self: &Fd) Error!Fd
```

Another descriptor for the same open file.

### Fd.set_cloexec

```otr
fn set_cloexec(self: &Fd) Error!void
```

Marks an adopted/inherited descriptor close-on-exec without changing its number.

### Fd.read

```otr
fn read(self: &Fd, buf: []out u8) Error! []mut u8
```

Reads up to `buf.len` bytes into `buf`, which need not hold values yet, and returns
the part it filled; that is empty at end of file.

### Fd.read_once

```otr
fn read_once(self: &Fd, buf: []out u8) Error! []mut u8
```

Calls libc read(2) once, without managed task I/O or an EINTR retry. `WouldBlock`
is returned directly, without waiting. A blocking descriptor can block the calling
thread, even in a fiber. This is not an Otr task cancellation point. Signal-handler
flags still control kernel syscall restarting. Returns only the initialized prefix,
empty at end of file. `buf` need not hold values yet.

### Fd.pread

```otr
fn pread(self: &Fd, buf: []out u8, offset: u64) Error! []mut u8
```

Reads at `offset` without changing the descriptor's file position.

### Fd.add_seals

```otr
fn add_seals(self: &Fd, seals: u32) Error!void
```

Adds memfd seals without changing descriptor ownership.

### Fd.write

```otr
fn write(self: &Fd, bytes: []u8) Error!usize
```

Writes some of `bytes`, and returns how many.

### Fd.try_lock_exclusive

```otr
fn try_lock_exclusive(self: &Fd) Error!bool
```

Takes an exclusive advisory lock on the open file without waiting (flock(2) with
`LOCK_EX | LOCK_NB`), as a single-instance lock: false when another descriptor
holds one. The lock goes with the descriptor's last copy.

### Fd.sync

```otr
fn sync(self: &Fd) Error!void
```

Waits until the file's data and metadata are on the disk (fsync(2)).

### Fd.read_u64

```otr
fn read_u64(self: &Fd) Error!u64
```

Reads the 8-byte counter an eventfd or timerfd gives.

### Fd.write_u64

```otr
fn write_u64(self: &Fd, v: u64) Error!void
```

Adds `v` to an eventfd's counter.

### Fd.get_flags

```otr
fn get_flags(self: &Fd) Error!u32
```

The file status flags (`O`), as F_GETFL gives them.

### Fd.set_flags

```otr
fn set_flags(self: &Fd, flags: u32) Error!void
```

Sets the file status flags that F_SETFL can change, such as `O.nonblock`.

### Fd.set_socket_option

```otr
fn set_socket_option(self: &Fd, level: i32, name: i32, value: i32) Error!void
```

Sets the integer socket option `name` at `level` (`SOL`, `SO`), such as the size of
a socket's buffers.

### Fd.bind_unix

```otr
fn bind_unix(self: &Fd, path: str) Error!void
```

Binds the Unix socket to `path`, which then names it in the file system.

### Fd.listen

```otr
fn listen(self: &Fd, backlog: i32) Error!void
```

Makes the bound stream socket accept connections, `backlog` of them waiting at most.

### Fd.accept

```otr
fn accept(self: &Fd, nonblock: bool) Error!Fd
```

The next connection to the listening socket; `WouldBlock` on a non-blocking one with
none waiting. The new socket is non-blocking when `nonblock` is set.

### Fd.accept_once

```otr
fn accept_once(self: &Fd, nonblock: bool) Error!Fd
```

One accept4 attempt. The listener's own flags control waiting; `nonblock` sets
the new socket's flags. Interrupted and ConnectionAborted are returned directly.

### Fd.send_to_unix

```otr
fn send_to_unix(self: &Fd, path: str, bytes: []u8) Error!usize
```

Sends `bytes` as one datagram to the Unix socket bound at `path`.

### Fd.chmod

```otr
fn chmod(self: &Fd, mode: u32) Error!void
```

Sets the file's permission bits, such as 0o600 for a socket only its owner may use.

### Fd.truncate

```otr
fn truncate(self: &Fd, len: u64) Error!void
```

Sets the size of the file, as for a `memfd` to be mapped.

## dup2

```otr
fn dup2(src: &Fd, dst: &mut Fd) Error!void
```

Makes `dst` refer to the open file `src` refers to, closing what `dst` referred to
before; its number stays the same.

## close_range

```otr
unsafe fn close_range(first: u32, last: u32, flags: u32) Error!void
```

Closes every descriptor from `first` to `last`; with `flags` 4 (CLOSE_RANGE_CLOEXEC)
it marks them close-on-exec instead. Unsafe: an `Fd` among them would later close a
number reused by something else. A child process gets the same effect safely through
`process.SpawnOptions.close_others`.

## open

```otr
fn open(path: str, flags: u32, mode: u32) Error!Fd
```

Opens the file at `path`, which must be shorter than 4096 bytes and hold no NUL;
`mode` gives a file that `O.creat` makes its permissions.

## Pair

```otr
const Pair = struct
```

Two descriptors made together, by `pipe2` (`a` is the read end, `b` the write end)
or `socketpair`. Fields cannot be moved out of a struct (spec O5), so `into_a` and
`into_b` keep one end and close the other, as a parent does once a child process has
the other end.

| Field | Type |
| --- | --- |
| <code>a</code> | <code>Fd</code> |
| <code>b</code> | <code>Fd</code> |

### Pair.into_a

```otr
fn into_a(self: Pair) Fd
```

Closes `b` and returns `a`.

### Pair.into_b

```otr
fn into_b(self: Pair) Fd
```

Closes `a` and returns `b`.

### Pair.deinit

```otr
fn deinit(self: Pair) void
```
