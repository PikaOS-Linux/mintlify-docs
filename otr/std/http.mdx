An HTTP/1.1 client (RFC 9110, RFC 9112) over `std.net` and `std.tls`: GET, POST and
the other methods with headers and a body, responses framed by Content-Length, chunked
transfer coding or the end of the connection, redirects up to a limit, a time limit
for connecting and one for the whole exchange, and proxies from `http_proxy`,
`https_proxy` and `no_proxy` (an https URL goes through the proxy by CONNECT).
Bodies coded `gzip` or `deflate` are decoded (`std.flate`), and those two are asked
for, unless `Options.decode` is off; other codings are handed over as they came.

`Fetch` is one exchange as a state machine over a non-blocking socket, for event
loops: `step` does what the socket allows without waiting, then `fd`, `want_read`,
`want_write` and `deadline` say what to wait for before calling it again. `fetch` is
the blocking call built on it. `Parser` reads a response from bytes, with no I/O.

```otr
var r = try http.fetch(env.io, heap, .{ url: "https://example.com/" }, .{ trust: .system{ env } })
defer r.deinit()
io.printf("{} {}\n", .{ r.status, r.body().len })
```

Host names are looked up by `net.Lookup`, the system's resolver on a thread of its own:
while it runs, `fd` is its descriptor and `want_read` is set, as for the socket.

`Client` keeps connections open between exchanges with the same server (HTTP/1.1
persistent connections, RFC 9112 §9.3) and starts each `Fetch` on an idle one when it
has one, which skips the lookup, the connect and the TLS handshake.

`http.parser` reads responses and `http.url` writes requests; their types are
re-exported here.

```otr
import std.http
```

## Example

```otr
import std
import std.http
import std.net
import std.string

// A one-request server, so the example needs no network: it answers any request.
fn serve_once(io: std.Io, listener: &net.Listener) net.Error!void {
    conn := try listener.accept(io)
    defer conn.deinit()
    var buf: [1024]u8
    _ = try conn.read(io, &out buf)
    try conn.write_all(io, "HTTP/1.1 200 OK\r\nContent-Type: text/plain\r\nContent-Length: 12\r\nConnection: close\r\n\r\nhello otter\n")
}

pub fn main(env: std.Env) !void {
    io := env.io
    heap := std.mem.heap

    listener := try net.listen(io, .{ host: "127.0.0.1" })
    defer listener.deinit()
    server := io.async(fn[io, &listener]() net.Error!void { return serve_once(io, &listener) })
    // If the client fails, cancelling ends the server's wait in accept.
    defer server.cancel(io) catch {}

    url := string.String.from_fmt(heap, "http://127.0.0.1:{}/greeting", .{ listener.port() })
    defer url.deinit()

    // `trust` names the roots that https servers are checked against.
    headers := [1]http.Header{ .{ name: "Accept", value: "text/plain" } }
    r := try http.fetch(io, heap, .{ url: url.as_str(), headers: &headers }, .{ trust: .system{ env }, timeout_ms: 5000 })
    defer r.deinit()

    std.io.printf("status {}\n", .{ r.status })
    std.io.printf("content-type: {}\n", .{ r.header("content-type") orelse "(none)" })
    std.io.printf("body: {}", .{ r.body() })
}
```

```text
status 200
content-type: text/plain
body: hello otter
```

### Fetch.fd

```otr
fn fd(self: &Fetch) i32
```

The descriptor to wait on: the host lookup's while it runs, then the socket; -1
between connections (never after `init` or `step` return without error, until the
exchange is done). It changes when a lookup ends or a redirect or the next of a
host's addresses needs a new connection, and the new descriptor may get the number
of one closed, which an epoll then no longer watches: `connection` tells them apart.

### Fetch.connection

```otr
fn connection(self: &Fetch) u32
```

A count of the descriptors `fd` has given so far, lookups and sockets: when it
changes, `fd` is a new one to register, whatever its number.

## Client

```otr
const Client = struct
```

Exchanges that keep their connections open for the next one with the same server
(scheme, host and port), so repeated requests skip the lookup, the connect and the
TLS handshake. `start` begins a `Fetch` on an idle connection when there is one, and
`finish` takes its response and keeps the connection when the server did (HTTP/1.1,
no `Connection: close`, a body framed by length or chunks). An idle connection the
server has closed is noticed and replaced. Proxied exchanges are not kept.

| Field | Type | Access | Description |
| --- | --- | --- | --- |
| <code>max_idle</code> | <code>usize = 16</code> | Public | Idle connections kept; the oldest is closed for a newer one. |
| <code>max_idle_ns</code> | <code>u64 = 30000000000</code> | Public | How long a connection may stay idle, in nanoseconds, before it is not used again. |
| <code>alloc</code> | <code>mem.Allocator</code> | Read-only |  |
| <code>idle</code> | <code>List(Idle)</code> | Read-only |  |
