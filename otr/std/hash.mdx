Checksums and hashes over bytes. Each hasher is a value with `init`, `update` for the
next part of the input, and `final`, which leaves the hasher as it was, so a running
digest can be read and fed on; `hash` digests one slice at once. CRC-32 and CRC-32C
use the CPU's carry-less multiply and crc32 instructions where it has them, and read
8 bytes per step through tables otherwise (slicing-by-8), as
SHA-256 and SHA-1 use the SHA instructions where there are some; `Wyhash`
is what Zig's hash maps use and matches it bit for bit; `XxHash64` is the stable
xxHash64. `Sha256` and `Sha1` are FIPS 180-4; SHA-1 is broken for signatures and only
for formats that name it, such as git object ids.

```otr
import std.hash
```

## Example

```otr
import std
import std.hash
import std.string

pub fn main() void {
    data := "hello otter"

    // One-shot hashes of a whole slice.
    std.io.printf("crc32    {x:0>8}\n", .{ hash.crc32(data) })
    std.io.printf("fnv1a64  {x:0>16}\n", .{ hash.Fnv1a64.hash(data) })
    std.io.printf("wyhash   {x:0>16}\n", .{ hash.Wyhash.hash(0, data) })
    std.io.printf("xxhash64 {x:0>16}\n", .{ hash.XxHash64.hash(0, data) })

    var hex = string.String.init(std.mem.heap)
    defer hex.deinit()
    digest := hash.Sha256.hash(data)
    hash.write_hex(&mut hex, &digest)
    std.io.printf("sha256   {}\n", .{ hex.as_str() })

    // Streaming: feed the input in parts and get the same digest.
    var h = hash.Sha256.init()
    h.update("hello ")
    h.update("otter")
    streamed := h.final()
    std.io.printf("streamed sha256 matches: {}\n", .{ std.mem.eql(u8, &streamed, &digest) })

    var crc = hash.Crc32.init()
    crc.update("hello ")
    crc.update("otter")
    std.io.printf("streamed crc32 matches: {}\n", .{ crc.final() == hash.crc32(data) })
}
```

```text
crc32    fb596ff2
fnv1a64  2545374bc75a86ed
wyhash   9b625a3966330e42
xxhash64 596fd7ea1af58076
sha256   8bfd001789db99cd9ec1a4a832c43670b7a8e7d06f7ee9460799682c4725fa5e
streamed sha256 matches: true
streamed crc32 matches: true
```

## Crc32

```otr
const Crc32 = Crc(0xedb88320)
```

CRC-32 as zlib, gzip, PNG and Ethernet compute it (polynomial 0x04c11db7, reflected).

## Crc32c

```otr
const Crc32c = Crc(0x82f63b78)
```

CRC-32C (Castagnoli, polynomial 0x1edc6f41, reflected), as iSCSI, ext4 and btrfs use.

## crc32

```otr
fn crc32(bytes: []u8) u32
```

The CRC-32 of `bytes`.

## crc32c

```otr

```

The CRC-32C of `bytes`.

## Crc

