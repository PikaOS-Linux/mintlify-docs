`otter-osd` shows transient on-screen indicators for volume, brightness, and lock keys. It runs as a daemon and accepts commands via a UNIX socket.

## Usage

Start the daemon (autostart at login):

```bash
otter-osd
```

Send commands from scripts, the status bar, or compositor keybindings:

```bash
otter-osd volume-up 5
otter-osd volume-down 10
otter-osd volume-mute-toggle
otter-osd brightness-up 5
otter-osd brightness-down 5
otter-osd caps-lock
otter-osd num-lock
otter-osd scroll-lock
```

The optional step value (default `5`) applies to volume and brightness commands.

[otter-timer](/apps/otter-timer) and [otter-rec](/apps/otter-rec) also communicate with `otter-osd` for completion notifications.

## Architecture

Single binary, two modes:

- **Daemon** (no args) — Connects to Wayland, creates a UNIX datagram socket, renders overlays on demand. Surfaces are created lazily and destroyed after timeout for zero idle RAM.
- **Client** (with args) — Sends a command to the daemon and exits.

Socket path: `$XDG_RUNTIME_DIR/otter-shell/osd-{WAYLAND_DISPLAY}.sock`

## Configuration

Config file: `~/.config/otter-shell/otter-osd.conf`

```conf
timeout = 1500
position = bottom_center
width = 340
height = 60
margin_bottom = 60
icon_size = 28
border_width = 2
bar_height = 14
font_size = 15
animation_duration = 150
```

Color fields inherit from [theme.conf](/configuration/themes) when omitted. Position and size changes require surface recreation — save the config and the daemon recreates the overlay on reload.
