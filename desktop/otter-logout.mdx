`otter-logout` opens a power menu for locking the session, logging out, suspending, rebooting, or shutting down. Bind it to a hotkey or the bar menu. It exits when you pick an action or dismiss the menu.

## Usage

```bash
otter-logout
```

Bind it to a compositor hotkey, for example `Super+Shift+E`:

```ini
# Hyprland
bind = $mainMod SHIFT, E, exec, otter-logout
```

## Configuration

Config file: `~/.config/otter-shell/otter-logout.conf`

```conf
icon_size = 64
button_size = 120
button_spacing = 24
highlight_destructive_actions = true
confirm_destructive_actions = true
overlay_color = "#000000aa"

lock_label = "Lock"
lock_icon = "system-lock-screen"
lock_exec = "loginctl lock-session"

logout_label = "Logout"
logout_icon = "system-log-out"
logout_exec = "loginctl terminate-session self"

sleep_label = "Suspend"
sleep_icon = "system-suspend"
sleep_exec = "systemctl suspend"

reboot_label = "Reboot"
reboot_icon = "system-reboot"
reboot_exec = "systemctl reboot"

shutdown_label = "Shutdown"
shutdown_icon = "system-shutdown"
shutdown_exec = "systemctl poweroff"
```

You can change each button's label, XDG icon name, and shell command. Colors inherit from [theme.conf](/configuration/themes) when omitted.

Reboot and shutdown are highlighted and require confirmation by default. Set `highlight_destructive_actions = false` to use normal colors. Set `confirm_destructive_actions = false` only if you want those actions to execute immediately.

## Lua surface

The menu uses native drawing unless it finds `logout.lua` on the UI script search path. A user script under `$XDG_DATA_HOME/otter-shell/ui/` (normally `~/.local/share/otter-shell/ui/`) overrides the system script. Edits can reload while the menu is open. A broken script keeps the last good frame or falls back to native drawing.

Manage overrides, **Native UI**, and hot reload in otter-settings **UI Scripts**. Lua describes the panel; native code still handles input and action execution. See [Settings](/desktop/otter-settings#ui-scripts-tab).

## Keybindings

| Key                         | Action                                                  |
| --------------------------- | ------------------------------------------------------- |
| Escape                      | Cancel confirmation, or close menu                      |
| 1–5                         | Select action; confirm destructive actions when enabled |
| Left / Shift+Tab            | Move left                                               |
| Right / Tab                 | Move right                                              |
| Enter                       | Activate selection or confirm the chosen action         |
| Click outside / Right-click | Close menu                                              |
