`otter-launcher` opens a centered search overlay. Same idea as fuzzel, rofi, or wofi, built on the shared Otter UI stack.

## Usage

```bash
otter-launcher
```

Bind to a compositor hotkey. For example `Super+D`:

```ini
# Hyprland
bind = $mainMod, D, exec, otter-launcher
```

Each run is one shot: open, search, launch (or press Escape), exit. A socket blocks duplicate overlays. Calling the launcher again closes the one that is already open.

## Launcher extensions

Extensions appear above application matches:

| Input | Action |
|-------|--------|
| `=2+3*4` or `calc 2+3*4` | Calculator result via [otter-calc](/apps/otter-calc) |
| `:heart` or `emoji heart` | Emoji search via [otter-emoji](/apps/otter-emoji) |
| `clip` or `clip query` | Clipboard history via [otter-clip](/apps/otter-clip) |

## Keyboard shortcuts

| Key | Action |
|-----|--------|
| Escape | Close launcher |
| Enter | Launch selected item or copy extension result |
| Up / Down | Move selection |
| Tab / Shift+Tab | Next / previous |
| Page Up / Page Down | Scroll by page |
| Home / End | First / last item |
| Ctrl+U | Clear search |
| Ctrl+W | Delete last word |
| Backspace | Delete character |

During IME composition, Escape and Enter go to the IME.

## Configuration

Config file: `~/.config/otter-shell/otter-launcher.conf`. A default config is created on first run.

<Tip>
  Change launcher size, colors, and placeholder text in [otter-settings](/desktop/otter-settings) under the **Launcher** tab.
</Tip>

```conf
width_percent = 30
height_percent = 35
border_width = 2
icon_size = 32
item_height = 48
input_height = 40
font_size = 16
placeholder_text = " Search applications..."
overlay_color = "#1b1b1b99"
```

Most color fields inherit from [theme.conf](/configuration/themes) when omitted.

## Terminal detection

For `.desktop` entries with `Terminal=true`, the launcher picks a terminal emulator:

1. `$TERMINAL` environment variable
2. Probes `$PATH` for `xdg-terminal-exec`, `foot`, `otter-term`, `ghostty`, `kitty`, `alacritty`, and others

Each terminal uses its correct exec flag (`-e`, `--`, etc.).
