Otter Shell is distributed as native packages for PikaOS. Packages are built and versioned together in the [otter-zenith](https://git.pika-os.com/otter-shell/otter-zenith) repository. Use **pikman** to install — it is the recommended package manager on PikaOS.

## System requirements

- **PikaOS** — Otter Shell packages target PikaOS repositories.
- **Wayland compositor** — Otter Shell is Wayland-only. Use any compositor that supports the protocols your chosen apps need (for example `zwlr_layer_shell_v1` for the status bar, launcher, and most overlays).
- **No Zig runtime needed** — Applications ship as native binaries. End users do not need Zig installed.

<Note>
  Otter Shell does **not** install a compositor for you. You choose and configure your own Wayland session (Hyprland, Sway, Niri, and others are common on PikaOS). The display manager (`otter-greeter`) uses Hyprland only for the login screen — your user session compositor is separate.

  Screenshot and color-picker tools (`otter-screenshot`, `otter-pick`, `otter-shot`) require the compositor to expose `ext_image_copy_capture_v1`.
</Note>

## Install with pikman

<Steps>
  <Step title="Update package lists">
    Refresh available packages:

    ```bash
    pikman update
    ```
  </Step>

  <Step title="Install Otter Shell">
    Install the full desktop metapackage:

    ```bash
    pikman install otter-shell
    ```

    This installs every component pinned to the same version. See the package table below for the full list.

    For optional speech tools (transcription and text-to-speech), also install:

    ```bash
    pikman install otter-shell-extras
    ```

    `otter-shell` **recommends** `otter-shell-extras` but does not require it — transcription and voice synthesis are not part of the base metapackage.
  </Step>

  <Step title="Install individual packages (optional)">
    If you only need specific tools, install packages by name:

    ```bash
    pikman install otter-term otter-bar otter-launcher
    ```
  </Step>
</Steps>

## Metapackages

| Metapackage | Contents |
|-------------|----------|
| `otter-shell` | Full desktop shell — bar, launcher, notifications, wallpaper, OSD, logout, settings, polkit, lock, idle, greeter, terminal, Jade pet, screenshot tools, clipboard, notes, timer, weather, and all other core helpers. Includes `otter-shell-fonts`. |
| `otter-shell-extras` | Optional speech tools only: `otter-transcribe` and `otter-vox`. |

## Packages in `otter-shell`

These packages are installed when you run `pikman install otter-shell`:

| Package | Description |
|---------|-------------|
| `otter-bar` | Status bar with widgets, system tray, and MPRIS |
| `otter-launcher` | Application launcher overlay |
| `otter-notifications` | Notification daemon (freedesktop.org spec) |
| `otter-wallpaper` | Wallpaper daemon |
| `otter-osd` | On-screen display for volume, brightness, and lock keys |
| `otter-logout` | Power menu overlay |
| `otter-settings` | Graphical settings editor |
| `otter-polkit` | Polkit authentication agent |
| `otter-lock` | Session lockscreen |
| `otter-idle` | Idle management daemon |
| `otter-greeter` | Display manager (login screen) |
| `otter-term` | Terminal emulator |
| `otter-jade` | Desktop pet |
| `otter-screenshot` | Region and fullscreen screenshots |
| `otter-shot` | Product-shot composer |
| `otter-rec` | Screen recorder |
| `otter-clip` | Clipboard manager |
| `otter-note` | Sticky notes |
| `otter-cal` | Calendar helper for the bar |
| `otter-calc` | Calculator helper |
| `otter-emoji` | Emoji picker helper |
| `otter-timer` | Countdown timer |
| `otter-pick` | Color picker |
| `otter-weather` | Weather fetcher and bar widget |
| `otter-shell-fonts` | Bundled fallback fonts |

**Not in either metapackage:** `otter-transcribe` and `otter-vox` (install via `otter-shell-extras`).

## Verify the installation

```bash
otter-term
```

A terminal window should open on your Wayland session. Continue with the [Quick Start](/quickstart) and [Session setup](/desktop/session-setup) guides to autostart shell daemons.
