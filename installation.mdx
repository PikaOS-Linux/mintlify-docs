Install Otter Shell's native PikaOS packages with pikman. They are built and versioned together in [otter-zenith](https://git.pika-os.com/otter-shell/otter-zenith). Gaming tools ship from [otter-gaming-utils](https://git.pika-os.com/otter-shell/otter-gaming-utils).

Otter Shell v0.13.0 uses otr 0.2.0 to build its native applications. You do not need a compiler to install or run the packages.

## System requirements

- Otter Shell packages target PikaOS repositories.
- You need a Wayland compositor that supports the protocols your apps use. The bar, launcher, and most overlays need `zwlr_layer_shell_v1`.
- Apps ship as native binaries with their Otter libraries statically linked. You do not need otr or Zig on your desktop.

<Note>
  Otter Shell does **not** ship a compositor. You pick and configure your own Wayland session. The PikaOS installer defaults to Zoolander when the install pool offers it. Hyprland, Sway, and Niri are also common. The display manager (`otter-greeter`) uses [Zoolander](/zoolander/overview) for the login screen, so `otter-greeter` depends on the separate `zoolander` package. Your user session compositor is separate.

Screenshot and color-picker tools (`otter-screenshot`, `otter-pick`, `otter-shot`) need the compositor to expose `ext_image_copy_capture_v1`.

</Note>

## Install with pikman

<Steps>
  <Step title="Update package lists">
    Refresh available packages:

    ```bash
    pikman update
    ```

  </Step>

  <Step title="Install Otter Shell">
    Install the desktop metapackage:

    ```bash
    pikman install otter-shell
    ```

    That installs the base desktop and its dependencies. It does not install every package built by zenith. See the exact metapackage dependencies below.

    For speech tools and Otter Assistant:

    ```bash
    pikman install otter-shell-extras
    ```

    `otter-shell-extras` is separate from the base metapackage. Transcription, voice synthesis, Assistant, and their model packages are not dependencies of `otter-shell`.

    For Otter Bench and the in-game HUD:

    ```bash
    pikman install otter-gaming-utils
    ```

    This metapackage is separate from `otter-shell`. See [otter-bench](/apps/otter-bench).

  </Step>

  <Step title="Install individual packages (optional)">
    For specific tools only:

    ```bash
    pikman install otter-term otter-bar otter-launcher
    ```

  </Step>
</Steps>

## Metapackages

| Metapackage          | Contents                                                                                                                                                                                                          |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `otter-shell-core`   | Core shell daemons, launcher, terminal, capture tools, overview, search, clipboard, weather, portal backend, and fonts. Exact direct dependencies are listed below.                                               |
| `otter-shell`        | `otter-shell-core` plus desktop applications, dock, taskbar, settings, greeter, night light, and plugin tools listed below.                                                                                       |
| `otter-shell-extras` | Speech tools (`otter-transcribe`, `otter-vox`), Otter Assistant (`otter-assist`, `otter-assistant`, `otter-assist-data`), and model packages (`otter-assist-model`, `otter-transcribe-model`, `otter-vox-model`). |
| `otter-gaming-utils` | Otter Bench suite: `otter-bench`, `otter-benchd`, `otter-benchctl`, `otter-hud`, `otter-bench-hardwared`.                                                                                                         |

## Exact metapackage dependencies

Zenith's `debian/control` defines these direct dependencies:

- **`otter-shell-core`**: `xdg-desktop-portal-otter`, `otter-bar`, `otter-launcher`, `otter-term`, `otter-wallpaper`, `otter-osd`, `otter-notifications`, `otter-polkit`, `otter-idle`, `otter-lock`, `otter-logout`, `otter-theme-gen`, `otter-search`, `otter-clip`, `otter-weather`, `otter-screenshot`, `otter-rec`, `otter-overview`, `otter-shell-fonts`.
- **`otter-shell`**: `otter-shell-core`, `otter-files`, `otter-dock`, `otter-taskbar`, `otter-keybindhelp`, `otter-settings`, `otter-pkg`, `otter-monitor`, `otter-jade`, `otter-clicker`, `otter-shot`, `otter-cal`, `otter-calc`, `otter-emoji`, `otter-note`, `otter-pick`, `otter-timer`, `otter-greeter`, `otter-shell-plugins`, `otter-plugin-factory`, `otter-nightlight`.
- **`otter-shell-extras`**: `otter-transcribe`, `otter-vox`, `otter-assist`, `otter-assistant`, `otter-assist-data`, `otter-assist-model`, `otter-transcribe-model`, `otter-vox-model`.

Dependencies of those packages can pull in more packages. For example, `otter-shell-plugins` depends on `otter-bluetooth-plugin`, and the portal backend depends on `otter-files` and `otter-pick`. The core metapackage is not a strict exclusion list for desktop apps.

## Packages in `otter-gaming-utils`

Installed by `pikman install otter-gaming-utils`. Built from [otter-gaming-utils](https://git.pika-os.com/otter-shell/otter-gaming-utils), not otter-zenith.

| Package                 | Description                                           |
| ----------------------- | ----------------------------------------------------- |
| `otter-bench`           | Desktop app for HUD layouts, sessions, and benchmarks |
| `otter-benchd`          | Metrics and session daemon                            |
| `otter-benchctl`        | CLI                                                   |
| `otter-hud`             | Vulkan / OpenGL overlay and launcher                  |
| `otter-bench-hardwared` | Privileged hardware helper (polkit)                   |

See [otter-bench](/apps/otter-bench) and [otter-hud](/apps/otter-hud).

## Verify the installation

```bash
otter-term
```

A terminal window should open on your Wayland session. Then follow [Quick Start](/quickstart) and [Session setup](/desktop/session-setup) to autostart shell daemons.
