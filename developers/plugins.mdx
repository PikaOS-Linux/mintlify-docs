Otter Shell loads third-party bar and launcher components as trusted `.so` plugins that contribute Surface Description (SD) through a small C ABI.

## Install

Install the examples package:

```bash
pikman install otter-shell-plugins
```

Packed plugins land at:

```
/usr/lib/otter-shell/plugins/<id>/
  plugin.conf
  libotter_plugin_<snake_id>.so
```

Hosts discover plugins in this order (first match per id wins):

1. `OTTER_PLUGIN_PATH` (colon-separated roots)
2. `$XDG_DATA_HOME/otter-shell/plugins`
3. `~/.local/share/otter-shell/plugins`
4. `/usr/lib/otter-shell/plugins`
5. `/usr/share/otter-shell/plugins`

Layout names in bar/launcher config are mandatory `plugin:<id>` (for example `plugin:hello-label`). The bare id lives in `plugin.conf`.

## Enable and configure

User gates live in otter-conf:

```
~/.config/otter-shell/plugins.conf
~/.config/otter-shell/plugins/<id>.conf
```

`plugins.conf` uses `<id>_enabled = true|false`. A missing key means **enabled**. **otter-settings** → **Plugins** writes these gates. Bar and launcher honor the same file before `dlopen`.

Example:

```conf
hello-label_enabled = true
bar-search_enabled = true
snippet-provider_enabled = false
```

Per-plugin settings files are reserved for schemas declared with `provides_settings = true`.

## Manifest (`plugin.conf`)

```conf
id = "hello-label"
name = "Hello label"
version = "0.1.1"
abi_version = 1
library = "libotter_plugin_hello_label.so"
provides_bar_widget = true
provides_launcher_provider = false
provides_launcher_sd_rows = false
provides_settings = false
```

## Factory CLI (`opf`)

Scaffold and pack plugins with [`otter-plugin-factory`](https://git.pika-os.com/otter-shell/otter-plugin-factory) (separate from the examples package):

```bash
export PATH="$PWD/bin:$PATH"   # from a factory checkout
# or: alias opf=…/otter-plugin-factory/bin/opf

opf new bar-widget my-chip
opf new launcher-provider my-provider

cd my-chip
opf build
opf pack                 # → zig-out/plugins/<id>/{plugin.conf,.so}
opf check                # manifest + otter_plugin_* exports
```

Publish into the system/examples layout as `/usr/lib/otter-shell/plugins/<id>/`. See the factory `docs/publishing.md`.

## ABI overview (v1)

Plugins export C symbols. Zig plugins may `@import` a mirrored `otter_plugin_abi` module. ABI major is `OTTER_PLUGIN_ABI_VERSION` (`1`).

Required exports:

| Symbol | Role |
|---|---|
| `otter_plugin_abi_version` | Must return `1` |
| `otter_plugin_init` / `otter_plugin_deinit` | Lifetime |
| `otter_plugin_query` | Fill `OtterPluginManifest` |

Bar (when `provides_bar_widget`):

- `otter_plugin_bar_attach` → `OtterPluginBarInstance` with vtable
- Vtable: `preferred_width`, `contribute`, `destroy`, optional `on_event`

Launcher (when provider / SD-row flags are set):

- `otter_plugin_launcher_query` / `otter_plugin_launcher_activate`
- Optional `otter_plugin_launcher_contribute_row` for custom SD rows

Host API during contribute (plugins emit SD; they do not scribble pixels):

- `sd_rect` / `sd_label` / `sd_hit_button`
- Optional `sd_text_input` for IME-backed fields (null-check on older hosts)
- `request_frame`, `log`

Events delivered through `BarVTable.on_event` include click, hover, focus/blur, and text-input (buffer/preedit flags).

Headers and mirrors live in `otter-bar` / `otter-launcher` / `otter-shell-plugins` (`include/otter_plugin_abi.h`, `abi/abi.zig`).

## Exemplars in `otter-shell-plugins`

| Layout id | Host | Proves |
|---|---|---|
| `plugin:hello-label` | bar | **M1** — real click callbacks (`on_event` toggles Hello↔Clicked) |
| `plugin:bar-search` | bar | **M2** — `sd_text_input` + text-input-v3 IME (preedit/commit/focus) |
| `plugin:cmd-watch` | bar | Interval command → label |
| `plugin:disk-free` | bar | `statvfs` free space + usage bar |
| `plugin:idle-inhibit` | bar | logind idle inhibit toggle via click |
| `plugin:snippet-provider` | launcher | Results provider + custom SD rows |

### hello-label (M1)

Smallest SD chip that proves host click delivery:

`bar_input_dispatch` → plugin slot → `BarVTable.on_event(CLICK)`.

Left click toggles label text (**Hello** ↔ **Clicked**) and background tint, then calls `host.request_frame`. No side-channel file.

```bash
# After pikman install otter-shell-plugins, or local pack:
# export OTTER_PLUGIN_PATH=$PWD/zig-out/plugins
# In otter-bar.conf:
#   layout_right = ["plugin:hello-label", "clock"]
```

### bar-search (M2)

Bar text field using host `sd_text_input` with Wayland text-input-v3. Focus the field, type, and confirm IME preedit/commit (not ASCII-only faking). Escape blurs. A `$XDG_RUNTIME_DIR/otter-bar-search` side-channel remains only as a fallback on old hosts.

```bash
# layout slot:
#   layout_center = ["plugin:bar-search"]
```

## Local development

```bash
git clone https://git.pika-os.com/otter-shell/otter-shell-plugins.git
cd otter-shell-plugins
zig build -Doptimize=ReleaseFast pack
export OTTER_PLUGIN_PATH="$PWD/zig-out/plugins"
```

ABI smoke (no Wayland):

```bash
zig build plugin-abi-smoke -- zig-out/plugins/hello-label/libotter_plugin_hello_label.so
```

## Trust

Installed `.so` plugins are fully trusted and share the host process. Prefer packages from `otter-shell-plugins` or plugins you built yourself.
