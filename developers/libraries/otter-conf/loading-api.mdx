Import `otter_conf.loader` and `otter_conf.serializer`.

## Loading

| Function                             | Purpose                                       |
| ------------------------------------ | --------------------------------------------- |
| `load(T, alloc, path, options)`      | Read one typed file                           |
| `load_from_slice(T, alloc, content)` | Parse existing bytes                          |
| `load_with_metadata`                 | Include file size and `mtime_ns: i64`         |
| `load_with_imports`                  | Resolve imports and return owned import paths |
| `load_or_create`                     | Load or create defaults                       |
| `ensure_config_exists`               | Create defaults when absent                   |

`loader.LoadOptions` controls `max_file_size` and `strict_custom_values`. Use strict custom parsing when malformed colors or other custom values must reject the whole update.

`ImportedLoadResult(T)` owns both its config and `List(String)` paths. Its `deinit()` drops both. Destructure the result if you need to move out the config; do not later deinitialize the moved whole result.

## Directories

`otter_conf.dir_loader.load_dir` loads matching files. `load_with_overrides` supports base and override directories. `DirLoadResult(T)` owns its entries and configs.

Use `get_by_filename`, `get_by_field`, or an entry's `filename()` rather than retaining borrowed names across mutation.

## Serialization and saves

`serializer.serialize(T, alloc, &cfg, options)` returns an owned `String`; drop it with `deinit()`. `serialize_into` reuses an existing output buffer.

`loader.save` borrows `&cfg`. `save_relative`, `save_defaults`, and `save_defaults_relative` serve the corresponding path/default cases. Saves and loads coordinate file locking; do not assume every save is an atomic rename.

`normalize.normalize` compares serialized output and writes only when needed. It rejects paths resolving outside the supplied user config root, including symlink escapes. Use normalization at the designated startup/editor boundary, not inside a file-watch reload loop.

## Lua

`otter_conf_lua` exposes `otter.config`: `dir`, `list`, `read`, and `watch` require `config`. Hosts configure directories before plugins load.

A host can also register `Typed(T, file).module("otter.config.<app>")`. Typed `get`, `table`, and `watch` require `config`; `set` requires `config-write` and strictly parses before writing the normalized user file. Only modules registered by the host are available.
