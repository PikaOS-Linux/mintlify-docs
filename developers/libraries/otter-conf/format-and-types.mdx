## File syntax

```ini
# Values not present keep their schema defaults.
name = "example"
width = 800
enabled = true
position = bottom
```

Use `#` comments, quoted strings, and unquoted boolean, number, or enum values. Nested structs flatten: `clock_time_format` addresses `config.clock.time_format`.

## Field types

| otr field                           | Use                                                |
| ----------------------------------- | -------------------------------------------------- |
| `bool`, integers, floats            | Scalar settings                                    |
| Enum                                | Unquoted tag name                                  |
| Fixed arrays                        | Fixed-size settings                                |
| `text.Text`                         | Static default or owned parsed text                |
| `?text.Text`                        | Optional text; an empty parsed string becomes null |
| `text.TextList`                     | List of strings                                    |
| `list.List(i64)` / `list.List(f64)` | Variable-length numeric lists                      |
| Nested struct                       | Flattened sections                                 |
| Custom `parse` / `to_str` type      | Colors and other string-valued types               |
| `dynamic.Dynamic(Elem, prefix)`     | Indexed entries                                    |

All parser-visible fields must be `pub` and have defaults. Configuration strings are not raw `str` fields: parsed text must remain owned after the input buffer goes away.

## Ownership and serialization details

A struct with `Text`, `TextList`, or `Dynamic` fields declares `deinit(self)` and delegates to `support.free_config`. Read `Text` with `as_str()`; clone it when another owner needs an independent value.

Null non-string optionals are omitted from serialization. A null optional string serializes as an empty quoted string. A `[N]u8` field parses as text but serializes as a numeric list; use `Text` for ordinary string settings.
