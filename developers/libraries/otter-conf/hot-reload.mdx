Import `otter_conf.watcher`. `Watcher.init()` creates an owned watcher without allocator arguments.

## Event-loop integration

1. Call `watch_config_path(path)` to watch the file's parent directory.
2. Put `get_fd()` into your existing event loop.
3. On readiness, call `drain_changed()`.
4. If it returns true, parse one replacement config.
5. Publish the replacement only after the full parse succeeds.

Directory watching survives editors that save by atomic rename. `IN_IGNORED` alone does not mean the config changed. Do not reload separately for every event in a burst.

## Imported files

`add_watches_for_imports(paths)` returns an owned list of descriptors. Refresh import watches when a successful reload changes the import graph.

For theme files, use `otter_theme.theme_watcher.ThemeWatcher` instead. It tracks the selected layers and imports as one graph.

## Metadata alternative

`loader.get_mtime(alloc, path)` returns nanoseconds as `i64`. `has_changed(alloc, path, previous_mtime)` supports code that already checks metadata. Long-running desktop applications should prefer descriptor-driven watches.

Never normalize or rewrite a file from its reload path. Failed edits retain the previous valid config; a watch event is not permission to replace it with defaults.
