Import service leaves under `otter_desktop.dbus`, for example `mpris`, `upower`, `network_manager`, `logind`, `power_profiles`, or `system_tray`.

Core `connection`, `message`, and `types` modules wrap basu. Drain available messages: one bus-processing call is not guaranteed to empty the queue.

## Services

The library includes notifications, screensaver inhibition/service support, UDisks, BlueZ, SCX, switcheroo-control, DisplayConfig, portals, accounts, seats, polkit, and fprintd alongside panel services.

GNOME DisplayConfig support reads current monitor state; it does not expose display reconfiguration. Protocol/service availability remains a runtime concern.

## Lua actions

The host registers only the bindings it intends to expose. Common modules and action gates are:

| Module                                                 | Action capability |
| ------------------------------------------------------ | ----------------- |
| `otter.desktop.mpris`                                  | `media`           |
| `otter.desktop.power_profiles`, `otter.desktop.logind` | `power`           |
| `otter.desktop.network`                                | `network`         |
| `otter.desktop.screensaver`                            | `idle-inhibit`    |
| `otter.desktop.notifications`                          | `notifications`   |
| `otter.desktop.tray`                                   | `tray`            |
| `otter.desktop.scx`                                    | `scheduler`       |
| `otter.desktop.udisks`                                 | `storage`         |
| `otter.desktop.bluetooth`                              | `bluetooth`       |

Public-state reads generally need no action capability. Notification send/close/subscription operations are gated, and notification IDs remain scoped to the sending plugin. A tray action validates item identity in addition to its current index.

`subscribe` callbacks are posted to the host loop. Service descriptors are opened lazily and closed after their last using plugin unloads. A lost bus removes its dead descriptor; a later call can reconnect.
