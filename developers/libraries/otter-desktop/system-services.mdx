## System state

Import `otter_desktop.sys.sysinfo`, `monitor`, `brightness`, or `falcond`.

`Monitor.refresh(env)` loads the application catalog when needed; `refresh_loaded` reuses it. Process/catalog storage grows with observed data rather than a fixed maximum process table.

Brightness operations cover panels, keyboard LEDs, and supported DDC paths. I/O and child reaping are explicit inputs to operations that use external helpers.

## PipeWire package

Audio/video modules are in `otter_desktop_pipewire`, not the main `otter_desktop` package.

- `pipewire`: device/default state and controls.
- `playback`: one-shot or streamed floating-point audio.
- `capture`: capture support used by transcription.
- `video_source`: exported video frames.

C glue translates callbacks into records processed by the otr owner. Resources may move with their owner; they are not arbitrary shared mutable handles. Playback deinitialization drains queued audio according to the stream contract.

The package uses vendored static PipeWire by default. `-D pipewire=system` selects the system library.

## Lua

| Module                     | Reads                                                                    | Actions      |
| -------------------------- | ------------------------------------------------------------------------ | ------------ |
| `otter.desktop.sysinfo`    | Memory, CPU, temperatures, disks, load, uptime, sensors                  | None         |
| `otter.desktop.monitor`    | Refreshed processes, applications, cores, GPUs, disks, networks, history | None         |
| `otter.desktop.brightness` | Devices and current levels                                               | `brightness` |
| `otter.desktop.volume`     | Sinks, sources, defaults, subscriptions                                  | `audio`      |

The host provides its environment when registering native-service modules. Volume opens PipeWire lazily; it is not implied by importing native UI primitives.
