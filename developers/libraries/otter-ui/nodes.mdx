`otter_ui.ui_frame.Node` is the native Surface Description node. There is no root `SurfaceNode` export.

## Constructors

| Group               | Constructors                                                                           |
| ------------------- | -------------------------------------------------------------------------------------- |
| Layout and surfaces | `row`, `column`, `rect`, `panel`                                                       |
| Text and actions    | `label`, `button`, `icon_button`                                                       |
| Editable values     | `text_input`, `checkbox`, `toggle`, `slider`, `number_input`, `select`, `color_picker` |
| Data and decoration | `progress`, `scrollbar`, `list_row`, `image`, `gradient_swatch`, `icon`                |

Additional content/spec variants live in `ui_frame_spec`. Check the constructor or `Content` variant instead of inventing a constructor for every spec name.

## Specs

Text-bearing specs borrow their strings. Examples include `ButtonSpec.text`, `TextInputSpec.text`, `SelectSpec.options`, and `ListRowSpec` labels. Keep source text alive through the render call.

`ButtonSpec.icon`, `ImageSpec.image`, and other image fields use `ImageHandle`; the frame resolves pixels through `FrameOptions.images`. Icons can use fallback text without storing a fallback-font pointer.

Optional colors and radii defer to resolved theme/style values. Disabled controls carry disabled hit/semantic state in addition to their appearance.

## Stable IDs

`Id.named_comptime("settings.save")` constructs a literal name. `Id.named` accepts runtime text. `child` and `child_int` derive hierarchical IDs for rows.

Keep IDs stable across frames. UI state is keyed by ID, not by node address. If two unrelated controls share an ID, their focus and keyed state collide.

## Native state remains explicit

A rendered spec describes current state; it does not own application data or automatically apply every edit. Handle dispatch results in your model and construct the next frame from the updated values.
