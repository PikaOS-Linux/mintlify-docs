Import `otter_ui.ui_frame` or the defining `ui_frame_spec` module.

## Size and placement

`LayoutSpec` controls `width`, `height`, minimum/maximum extents, `padding`, `gap`, `flex`, axis alignment, and clipping.

| `SizeRule`        | Meaning                    |
| ----------------- | -------------------------- |
| `.fit`            | Use measured content size  |
| `.fill`           | Use available layout space |
| `.fixed{ value }` | Use an explicit extent     |

`LayoutSpec.fixed(width, height)` builds two fixed sizing rules. `AxisAlign` has `start`, `center`, `end`, and `stretch`.

Rows distribute children horizontally; columns distribute vertically. Gaps separate siblings, padding insets content, and flex participates in distributing remaining space among fill children. Bounds and min/max limits constrain final sizes.

## Borrowed trees

`Node` is a `ref struct` that borrows child slices and text. Construct trees for the current render call, not as persistent pointer graphs.

`Node.row(id, layout, children)` and `Node.column(id, layout, children)` accept `[]Node`. Supply stable `Id` values independently of the stack storage used for nodes.

## Virtualized geometry

`UniformList` and `UniformGrid` compute visible ranges, hit indices, content height, and scroll positions without materializing every item. Build only the visible native rows for large lists.

Use logical geometry with an explicit rendering `Scale`. Layout positions use signed coordinates; extents use the shared geometry types.
