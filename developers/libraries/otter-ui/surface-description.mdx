Import `otter_ui.ui_frame`.

## State and frame lifetime

`UiState(caps)` owns commands, hit regions, element records, keyed state slots, and a per-frame label arena. Initialize it with `init()`.

`UiFrame(caps)` is a `ref struct`. `state.begin(FrameOptions)` borrows the state, theme, font, image store, and optional shaping resources for one frame. Do not keep a frame across updates or rasterize through state while that borrow is live.

```otr
import otter_ui.ui_frame

pub fn main() !void {
    var state = ui_frame.UiState(.{}).init()
    bounds := ui_frame.Rect{ x: 0, y: 0, width: 320, height: 100 }
    {
        var frame = state.begin(.{ viewport: bounds, scale: 1, scale_q8: 256 })
        root := ui_frame.Node.rect(ui_frame.Id.root, .{ width: .fill, height: .fill }, .{})
        _ = try frame.render(&root, bounds)
        try frame.finish()
    }
    _ = state.command_slice()
}
```

## Frame options

`FrameOptions` supplies the viewport, integer ceiling `scale`, exact `scale_q8`, optional font/theme/styles/images, input snapshot, and optional text shaping resources/provider. A zero `scale_q8` derives the exact factor from the integer scale. Set shaping resources when text requires them; do not keep backend pointers in the command list.

## Lifecycle

1. `begin` resets per-frame output.
2. `render` measures and places the root tree, emits commands, and records hits.
3. Queue overlays after their anchor content is laid out.
4. `finish` orders overlay/tooltip output.
5. End the frame's borrow.
6. `state.rasterize` borrows the destination surface, optional `TextContext`, image source, damage, and full-redraw flag.

## Capacity and ownership

`Capacities` bounds commands, strings, elements, hits, overlays, and state slots. `label_bytes` bounds copied label text; zero derives a capacity from record counts. Capacity-sensitive frame operations return `FrameError.Overflow`.

`command_storage = false` is only for input/layout states whose app owns external commands. Rendering entry points intentionally reject that configuration.

Use `state.release_icons(&mut images)` to release UI-owned cached image handles. Store-owned pixels and borrowed frame resources have separate lifetimes.
