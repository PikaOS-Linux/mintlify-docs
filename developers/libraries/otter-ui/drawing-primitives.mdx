Native drawing helpers live under `otter_ui.drawing.<module>`, not a `drawing.zig` root import.

| Module               | Purpose                                     |
| -------------------- | ------------------------------------------- |
| `core`               | Basic bounds and drawing support            |
| `text`               | Truncation, wrapping, text placement        |
| `frame`              | Borders, panels, baselines                  |
| `input`              | Input boxes and related geometry            |
| `controls`           | Buttons, toggles, progress controls         |
| `select`, `dropdown` | Select/dropdown drawing and hit geometry    |
| `color_picker`       | HSV, picker geometry, password/auth helpers |

Helpers emit into borrowed command lists. Pass a font explicitly where measurement is needed; there is no implicit widget-owned font pointer. Names use `snake_case`.

## Text lifetimes

`TruncatedText(cap)` stores a bounded result value. Read its `text(original)` with the original input: fitting text returns the input, while truncated text returns the stored shortened result. Keep the returned view within the relevant lifetime.

Use the frame's measurement methods when a frame already owns the font loan. Do not pass a second mutable borrow of the same font beside that frame.

## Lua

`otter.ui.draw` exposes pure geometry/color operations, not the entire native drawing command list. It includes baselines, joined corners, input/dropdown/color-picker hit calculations, HSV conversion, and password masking. Option indices are one-based in Lua.

`otter.ui.style.resolve(theme_table, profile)` returns resolved style tables from `otter.theme.get()` data. These read-only helpers need no capability. Visible Lua drawing still goes through `sd.*`.
