`otter-utils` supplies small Linux and application helpers through `otter_utils.<module>` imports. It has no package root barrel.

| Modules                                                       | Purpose                                       |
| ------------------------------------------------------------- | --------------------------------------------- |
| `log`                                                         | Scoped logging, counters, periodic reporters  |
| `fixed_string`                                                | UTF-8-aware bounded configuration text        |
| `xdg_paths`, `runtime_paths`, `runtime_state`, `legacy_paths` | Shared filesystem locations and session state |
| `inotify`                                                     | File and directory event watching             |
| `process`, `command`, `shutdown`                              | Child-process and lifecycle helpers           |
| `unix_socket`, `runtime_auth`                                 | Local IPC support                             |

Use otr standard-library containers and path types instead of `BoundedArray` and `FilePath`, which are not exported. Environment-dependent helpers take `std.Env`; there is no global `io.install` step.
