`otter-conf` maps flat `key = value` files to defaulted otr structs. Import leaf modules such as `otter_conf.loader`, `otter_conf.parser`, and `otter_conf.serializer`.

Every field that a configuration file may set must be `pub`. String fields use `otter_conf.text.Text`; structs owning strings need a consuming `deinit`.

```otr
import std.mem
import otter_conf.loader
import otter_conf.support
import otter_conf.text

const Config = struct {
    pub name: text.Text = text.Text.of("example")
    pub width: u16 = 640

    pub fn deinit(self: Config) void {
        support.free_config(Config, self)
    }
}

pub fn main() !void {
    cfg := try loader.load_from_slice(Config, mem.heap, "width = 800")
    defer cfg.deinit()
    _ = cfg.width
}
```

Parsing starts from defaults. Unknown keys are skipped. Nested struct fields flatten into underscore-separated keys.
