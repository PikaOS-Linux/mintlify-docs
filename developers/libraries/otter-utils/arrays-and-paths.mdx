## Bounded containers

`otter-utils` has no container types of its own. Use `std.bounded.BoundedList(T, N)` for fixed-capacity records and `std.bounded.InlineString(N)` for bounded text. Use `std.list.List(T)` when capacity must grow.

A container that allocates keeps its allocator, and you release it with `deinit()`. See [Ownership and borrowing](/otr/memory/ownership-and-borrowing).

## Fixed strings

`otter_utils.fixed_string.FixedString(N)` stores at most `N` bytes inline. `set` never fails. It keeps what fits and cuts before a UTF-8 sequence that would not fit whole.

```otr
import std
import otter_utils.fixed_string

pub fn main() void {
    var label = fixed_string.FixedString(8).from("Otter Shell")
    std.io.printf("{} ({} bytes)\n", .{ label.get(), label.len() })   // Otter Sh (8 bytes)

    label.set("none")
    if label.is_none() {
        label.clear()
    }
}
```

| Method | Purpose |
| --- | --- |
| `init()`, `from(value)` | An empty string, or one holding `value` |
| `set(value)`, `clear()` | Replace or empty the contents |
| `get()`, `len()`, `is_empty()` | Read the contents |
| `eql(other)` | Compare with a `str` |
| `is_none()` | True for empty text, `none` and `None`, which is how configs switch an optional value off |
| `as_cstr()` | The contents as a `[:0]u8` for C |

Parsed configuration fields use `otter_conf.text.Text`, which borrows from the loaded config. See [Format and types](/developers/libraries/otter-conf/format-and-types).

## Path buffers

Use `std.path` for general path handling. The Otter Shell path builders write into an `otter_utils.xdg_paths.Buf`, a fixed buffer of `std.path.max_len` bytes. The `str` a builder returns borrows that buffer, so use it before you write to the buffer again.

```otr
import std
import otter_utils.xdg_paths

pub fn main(env: std.Env) void {
    var buf = xdg_paths.Buf.init()
    if xdg_paths.otter_config_path(env, &mut buf, "otter-bar.conf") |p| {
        std.io.println(p)
    }
}
```

`Buf` has `push`, `push_str` and `set`, which return `error.Full` when the text does not fit, plus `clear`, `len` and `as_str`. `xdg_paths.compose(&mut buf, parts)` writes a tuple of strings one after another and returns null when they do not fit.
