## Bounded containers

Use `std.bounded.BoundedList(T, N)` for fixed-capacity records and `std.bounded.InlineString(N)` for bounded text. Use `std.list.List(T)` when capacity must grow. The Zig `BoundedArray` wrapper is not available.

Containers that allocate keep their allocator. Drop an owned list with `deinit()` rather than passing the allocator again.

## Configuration strings

`otter_utils.fixed_string.FixedString(N)` wraps inline text. `set` keeps what fits and does not split a UTF-8 sequence.

```otr
import otter_utils.fixed_string

pub fn main() void {
    var title = fixed_string.FixedString(32).init()
    title.set("Otter Shell")
    _ = title.get()
}
```

Methods include `from`, `set`, `get`, `len`, `is_empty`, `clear`, `eql`, `is_none`, and `as_cstr`. `is_none` recognizes empty text, `none`, and `None`.

## Paths

Use `std.path` for general path handling. Shared Otter Shell path builders use `otter_utils.xdg_paths.Buf`. A returned `str` borrows that buffer: consume it before reusing or clearing the buffer.

Use `otter_conf.text.Text` for parser-owned configuration fields. `FixedString` is not a replacement for the configuration parser's ownership model.
