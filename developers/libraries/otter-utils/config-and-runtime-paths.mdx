## XDG paths

Import `otter_utils.xdg_paths`. Builders take `env: std.Env` and an output `&mut Buf`; they return `?str` when a base is missing or the result does not fit.

| Function                                 | Location                                                              |
| ---------------------------------------- | --------------------------------------------------------------------- |
| `otter_config_path` / `otter_config_dir` | `$XDG_CONFIG_HOME/otter-shell/`, else `$HOME/.config/otter-shell/`    |
| `otter_data_path` / `otter_data_dir`     | `$XDG_DATA_HOME/otter-shell/`, else `$HOME/.local/share/otter-shell/` |
| `otter_cache_path` / `otter_cache_dir`   | `$XDG_CACHE_HOME/otter-shell/`, else `$HOME/.cache/otter-shell/`      |

Empty or relative XDG base variables are ignored. Runtime paths require an absolute `XDG_RUNTIME_DIR`; there is no HOME fallback for that variable.

`ensure_dir_path` creates missing parents. `make_private_dir` and `ensure_otter_cache_dir` provide private-directory helpers.

## Session state

Import `otter_utils.runtime_state` for Do Not Disturb and wallpaper state:

- `dnd_state_path`, `is_dnd_enabled`, `set_dnd_enabled`, `toggle_dnd`.
- `wallpaper_state_path`, `open_wallpaper_state_file`, `wallpaper_state_watch_path`.
- `WallpaperStateIterator`, `first_wallpaper_path`, `wallpaper_path_for_output`.

DND changes use a lock and atomic replacement. Wallpaper state uses `output_name=absolute_path` lines. The reader retains support for the legacy `/tmp/<uid>/otter-wallpaper-state` file.

Only the wallpaper daemon publishes wallpaper state. Consumers read it; they must not write their own competing copy.

Set `XDG_CONFIG_HOME` and `XDG_RUNTIME_DIR` to temporary directories in tests.
