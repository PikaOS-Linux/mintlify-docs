Import `otter_utils.log`. `Scoped(scope)` formats allocation-free stderr lines with a padded scope name. `StdScoped(scope)` provides the alternate standard-log layout.

```otr
import otter_utils.log

const logger = log.Scoped("example")

pub fn main() void {
    logger.info("ready", .{})
}
```

`set_level`, `level`, and `enabled` manage the process-wide level. The level is atomic; a change applies across threads.

## Counters

`Counter` is plain state owned by your loop. Its methods are `inc`, `add`, `get`, and `reset`. `reset` returns the previous count.

Use `StaticCounter.init()` for a shared top-level atomic counter. Do not make every local counter atomic.

## Reporters

`Reporter(scope, interval_seconds)` limits how often you print rate summaries. Keep it in the owner's state and call its reporting methods from normal loop activity.

Lines have a 512-byte bound. Oversized messages end in `...`. Use standard otr formatting placeholders, not Zig-only formatting APIs.
