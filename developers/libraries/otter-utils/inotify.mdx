Import `otter_utils.inotify`. `Watcher.init()` creates an owned Linux watcher; call `deinit()` once when its owner shuts down.

| Method                                            | Purpose                                         |
| ------------------------------------------------- | ----------------------------------------------- |
| `add_watch(path, mask)`                           | Add or update a watch and return its descriptor |
| `remove_watch(wd)` / `remove_watch_by_path(path)` | Remove a watch                                  |
| `poll_fd()`                                       | Descriptor for your event loop                  |
| `get_path(wd)`                                    | Path recorded for a descriptor                  |
| `next_event()`                                    | Next borrowed event, or null when drained       |
| `has_pending_events()`                            | Whether the current buffer has unread events    |
| `dropped_event_count()`                           | Count rejected or dropped events                |

An `Event` is a `ref struct`. Its name points into the watcher's buffer and lasts only until the next `next_event()` call. Copy text you need to retain.

Event helpers include `is_modified`, `is_deleted`, `is_created`, `is_moved`, and `is_ignored`.

## Configuration watches

For configuration files, prefer `otter_conf.watcher.Watcher.watch_config_path`. It watches the parent directory so atomic-save renames do not invalidate the watch. Drain a burst, then reload once. An ignored watch event alone is not a configuration change.

Keep event draining inside your existing descriptor loop. Do not poll the filesystem on a periodic timer.
