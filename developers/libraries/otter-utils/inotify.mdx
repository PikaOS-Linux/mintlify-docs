Import `otter_utils.inotify`. `Watcher.init()` opens a non-blocking inotify descriptor and returns an owned `Watcher`. Release it with `deinit()`.

| Method | Purpose |
| --- | --- |
| `add_watch(path, mask)` | Adds a watch and returns its descriptor. A path you already watch keeps its descriptor and takes the new mask |
| `remove_watch(wd)`, `remove_watch_by_path(path)` | Remove a watch |
| `poll_fd()` | The descriptor for your event loop |
| `get_path(wd)` | The path recorded for a watch descriptor |
| `next_event()` | The next event without blocking, or null when none is waiting |
| `has_pending_events()` | Whether the current buffer holds unread events |
| `dropped_event_count()` | How many truncated records the watcher discarded |

`Mask.file_changes` and `Mask.dir_changes` are ready-made masks for one file and for a directory's entries. The `IN` struct holds the individual flags, such as `IN.close_write` and `IN.moved_to`.

```otr
import std
import std.runtime
import otter_utils.inotify

pub fn main(env: std.Env) !void {
    var watcher = try inotify.Watcher.init()
    defer watcher.deinit()

    wd := try watcher.add_watch("/tmp", inotify.Mask.dir_changes)
    std.io.printf("watching {}\n", .{ watcher.get_path(wd).? })

    var fds = [1]runtime.PollFd{
        .{ fd: watcher.poll_fd(), events: runtime.Poll.read, revents: 0 },
    }
    _ = try env.io.poll(&mut fds[0..], null)

    for {
        event := watcher.next_event() orelse break
        if event.is_ignored() { continue }
        if event.is_created() {
            std.io.printf("created {}\n", .{ event.name orelse "" })
        }
    }
}
```

## Events

An `Event` is a `ref struct` with `wd`, `mask`, `cookie` and `name`. `name` is the entry inside a watched directory. It points into the watcher's buffer and lasts until the next `next_event()` call, so copy any text you keep.

The helpers `is_modified`, `is_deleted`, `is_created`, `is_moved` and `is_ignored` test the mask. `is_ignored` means the kernel removed the watch. Treat it as a lost watch and not as a change to the file.

## Configuration watches

For configuration files, use `otter_conf.watcher.Watcher`. Its `watch_config_path` watches the parent directory, so a save that renames a new file into place keeps the watch alive. See [Hot reload](/developers/libraries/otter-conf/hot-reload).

Add `poll_fd()` to the descriptor loop your app already runs, and drain events when it becomes readable.
