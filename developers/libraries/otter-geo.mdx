`otter-geo` provides dependency-free layout and pixel value types. Import `otter_geo.rect`, `otter_geo.transform`, or `otter_geo.color`.

Positions are signed `i32`; geometry extents are `u16`. Colors belong to this package and do not require the renderer.

```otr
import otter_geo.rect as geo

pub fn main() void {
    bounds := geo.Rect{ x: 0, y: 0, width: 100, height: 40 }
    point := geo.Point{ x: 20, y: 10 }
    if bounds.contains_point(point) {
        inner := bounds.remove_padding(geo.Padding.uniform(8)) orelse return
        _ = inner
    }
}
```

`Transform` stores a 2×2 matrix in signed 16.16 fixed point. Use `Color.parse` for configuration colors and `Color.from_rgba` for packed RGBA literals.
