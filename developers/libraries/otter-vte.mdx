`otter-vte` holds the terminal rendering that otter-term uses, packaged so that other apps can draw terminal output the same way. It turns a grid of cells into drawing commands and rasterizes them with otter-render. It does not own a PTY and does not parse escape sequences. Your app supplies the cells.

The package is `otter_vte`. It has no root module. Import `otter_vte.command_list`, `ops`, `cell_glyphs`, `cells`, `cell_renderer`, `renderer` or `snapshot`.

```toml
[dependencies]
otter_geo = { path = "../../otter-geo/otr" }
otter_render = { path = "../../otter-render/otr" }
otter_vte = { path = "../../otter-vte/otr" }
```

## How the modules fit

| Module | Role |
| --- | --- |
| `cells` | The `Cell` view, `Rgb`, `StyleFlags` and the `CellVisitor` interface. |
| `snapshot` | Walks a terminal snapshot stored as column slices and visits each cell. |
| `cell_renderer` | A visitor that turns cells into background runs, text runs and glyph operations. |
| `command_list` | `DynamicCommandList`, a command list that grows with the grid. |
| `ops`, `cell_glyphs` | Powerline shapes, block rectangles and the geometry of box, block and braille glyphs. |
| `renderer` | `Renderer`, which owns the lists and operation buffers for one terminal view. |

A frame goes through three steps. Prepare the `Renderer` for the grid size, visit the cells with a `CellRenderer` draw context, then rasterize the layers onto a surface. [Cell renderer](/developers/libraries/otter-vte/cell-renderer) shows the whole sequence.

## Lua

The `otter_vte_lua` package provides `otter.vte`. It gives a Lua widget the same glyph geometry and powerline shapes, drawn onto canvases the plugin owns. Nothing here acts on the system, so it needs no capability. It does not create a terminal session.

```lua
local vte = require("otter.vte")

local rects, alpha = vte.glyph(0x2584, 0, 0, 8, 16)   -- nil when the font draws it
local kind, dir = vte.powerline(0xe0b4)               -- "round", "right"

local c = vte.canvas(64, 32, 2)                       -- logical size, scale
vte.clear(c, 0xff000000)
vte.draw_powerline(c, "triangle", "right", 0, 0, 8, 16, 0xffff0000, 0xff000000)
local argb = vte.pixel(c, 3, 10)                      -- a physical pixel
vte.free(c)
```
