Typed config structs shared across apps and `otter-settings`.

Schemas for bar, launcher, dock, notifications, wallpaper, OSD, transcribe, logout, polkit, lock, idle, and more.

When you add a configurable app, define structs here and register a settings tab in `otter-settings/src/tabs.zig`.
