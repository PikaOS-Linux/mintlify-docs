Import `otter_render.command_list`. `DefaultCommandList` is `CommandList(2048, 32 * 1024)`: 2048 commands and 32 KiB of string storage.

```otr
import otter_geo.color
import otter_geo.rect
import otter_render.command_list
import otter_render.scale

pub fn main() void {
    var cmds = command_list.DefaultCommandList.init()
    cmds.set_scale(scale.Scale.one)
    cmds.solid_rect(rect.Rect{ x: 0, y: 0, width: 100, height: 40 }, color.Color.black)
    _ = cmds.overflowed()
}
```

## Commands

Use `solid_rect`, `blend_rect`, `rect_outline`, `rounded_solid_rect`, `rounded_blend_rect`, `rounded_rect_outline`, `circle`, `text`, `text_styled`, `image`, `sprite`, `graph`, and `clear` as needed.

`scissor_push` / `scissor_pop` bound nested drawing. Balance pushes and pops. `reset` prepares the list for another frame; `overflowed` reports capacity loss.

Image commands store generational `ImageHandle` values. Put image pixels in an `ImageStore` or another `ImageSource`; stale handles draw nothing.

## Rasterization

`quad_renderer.rasterize` takes the command-list type, borrowed list, mutable surface, optional mutable `TextContext`, an `ImageSource`, optional damage rectangles, and a full-damage flag.

`TextContext` lends `Font`, optional `TextSystem`, and optional `ShapeScratch` for that call. The command list does not store those pointers.

Pass logical damage and scale consistently. Keep render-culling damage separate from submit-only damage when moving existing pixels.
