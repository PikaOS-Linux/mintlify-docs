## Connection

`connection.Connection.init(interest)` connects to the compositor and binds the globals it advertises. Each bound global is an optional field on the connection, such as `conn.compositor`, `conn.shm`, `conn.layer_shell` and `conn.seat`. `hub.lend` borrows one, or returns `null` when the compositor does not have it.

```otr
comp := hub.lend(wl.Compositor, &conn.compositor) orelse return error.NoCompositor
shell := hub.lend(zwlr.LayerShellV1, &conn.layer_shell) orelse return error.NoLayerShell
```

| Method | Use |
| --- | --- |
| `dispatch(io)` | Block until events arrive, then dispatch them. |
| `dispatch_or(io, extra_fd, deadline)` | The same, and also wake for one extra descriptor or a monotonic deadline in nanoseconds. Returns `.wayland`, `.extra` or `.timeout`. |
| `dispatch_pending(io)` | Dispatch what is already queued without blocking. |
| `roundtrip()` | Send pending requests and wait for the compositor to answer them. |
| `flush()`, `write_pending()` | Send queued requests. While `write_pending()` is true, also wait for the socket to become writable. |
| `fd()` | The socket descriptor, for your own poll set. |
| `next_global()` | The next global the connection hands to you. |

To wait on several descriptors, put them in one `linux.Epoll` and pass its descriptor as `extra_fd`.

### Globals you own

Outputs and a few managers are handed to your app instead of being kept on the connection. `GlobalInterest` selects which ones you want, and `next_global()` returns each as a `GlobalEvent`. An event owns its proxy, so every arm of the switch has to take it or release it.

```otr
import otter_wayland.capture_output
import otter_wayland.connection

fn take_globals(conn: &mut connection.Connection, outputs: &mut capture_output.OutputList) void {
    for {
        g := conn.next_global() orelse break
        switch g {
            .output_added |o| => {
                output, name := o
                outputs.add_output(output, name)
            }
            .output_removed |r| => outputs.remove_output(r.name)
            .xdg_output_manager |x| => {
                manager, _ := x
                outputs.set_xdg_output_manager(manager)
            }
            .output_manager |x| => {
                manager, _ := x
                outputs.init_output_manager(manager)
            }
            .seat_added => {}
            .workspace_manager |x| => {
                manager, _ := x
                manager.deinit()
            }
            .dwl_ipc_manager |x| => {
                manager, _ := x
                manager.deinit()
            }
            .toplevel_manager |x| => {
                manager, _ := x
                manager.deinit()
            }
            .ext_toplevel_list |x| => {
                list, _ := x
                list.deinit()
            }
            .toplevel_mapping |x| => {
                manager, _ := x
                manager.deinit()
            }
        }
    }
}
```

When outputs are all you track, `outputs.take_global(g)` handles the two output events and returns every other event for you to release.

## Hub records

Listeners for objects you create yourself deliver into the hub too. Set the listener with a handler from `otter_wayland.events`, then read the records with a `hub.Reader`. Each record carries the `wl.Id` it came from in `from`.

```otr
surf := comp.create_surface()
defer surf.deinit()
surf.set_listener(hub.Hub, &hub.context, events.Surface)

var records = hub.Reader(hub.SurfaceRecord).init(&conn.hub.surface)
defer records.deinit()

for {
    e := records.next(&conn.hub.surface) orelse break
    if e.from.raw != surf.id().raw {
        continue
    }
    switch e.record {
        .preferred_buffer_scale |ps| => rescale(ps.factor)
        else => {}
    }
}
```

## Layer-shell surfaces

`otter_wayland.layer` has the `Layer`, `Anchor` and `KeyboardInteractivity` values and their wire conversions. `Anchor` has presets for common placements: `top_bar`, `bottom_bar`, `left_panel`, `right_panel` and `fullscreen`.

This program creates a 32 pixel panel along the top edge and paints it on every configure.

```otr
import std
import std.mem
import otter_geo.color
import otter_wayland.connection
import otter_wayland.damage
import otter_wayland.events
import otter_wayland.hub
import otter_wayland.layer
import otter_wayland.wayland
import otter_wayland_render.renderer

const wl = wayland.wl
const zwlr = wayland.zwlr

pub fn main(env: std.Env) !void {
    var conn = try connection.Connection.init(.{})
    defer conn.deinit()

    comp := hub.lend(wl.Compositor, &conn.compositor) orelse return error.NoCompositor
    shell := hub.lend(zwlr.LayerShellV1, &conn.layer_shell) orelse return error.NoLayerShell

    surf := comp.create_surface()
    defer surf.deinit()
    surf.set_listener(hub.Hub, &hub.context, events.Surface)
    ls := shell.get_layer_surface(&surf, null, layer.layer_to_wire(.top), "my-panel")
    defer ls.deinit()
    ls.set_listener(hub.Hub, &hub.context, events.LayerSurface)
    ls.set_size(0, 32)
    ls.set_anchor(layer.Anchor.top_bar.to_wire())
    ls.set_exclusive_zone(32)
    ls.set_keyboard_interactivity(layer.interactivity_to_wire(.none))
    surf.commit()

    var records = hub.Reader(hub.SurfaceRecord).init(&conn.hub.surface)
    defer records.deinit()
    var r: ?renderer.Renderer = null
    defer mem.drop(?renderer.Renderer, r)
    var tracker = damage.DamageTracker.init()
    var running = true

    for running {
        try conn.dispatch(env.io)
        if (&mut r).* |mut rr| {
            rr.pump(&conn.hub)
        }
        for {
            e := records.next(&conn.hub.surface) orelse break
            if e.from.raw != ls.id().raw {
                continue
            }
            switch e.record {
                .layer_configure |cfg| => {
                    ls.ack_configure(cfg.serial)
                    shm := hub.lend(wl.Shm, &conn.shm) orelse return error.NoShm
                    next := try renderer.create_renderer(&conn.hub, shm, @truncate(u16, cfg.width), @truncate(u16, cfg.height), 1)
                    mem.drop(?renderer.Renderer, mem.replace(?renderer.Renderer, &mut r, next))
                    tracker.mark_full_damage()
                    if (&mut r).* |mut rr| {
                        if rr.acquire() |b| {
                            var buf = b
                            buf.surface().clear(color.Color.surface)
                            rr.submit(buf, &surf, &tracker)
                            tracker.commit_frame()
                            surf.commit()
                        }
                    }
                }
                .layer_closed => running = false
                else => {}
            }
        }
    }
}
```

Layer shell is a compositor protocol, and Otter Shell does not ship a compositor. Check for `conn.layer_shell` as the example does.

## XDG toplevels

`xdg_toplevel.XdgToplevel` wraps a normal window: the surface, the xdg objects, decorations and scale tracking. Pump it, then drain its events.

```otr
var top = try xdg_toplevel.XdgToplevel.create_with_options(&conn, "Otter Examples", "otter-examples", .{ request_server_side_decorations: true })
defer top.deinit()
top.set_min_size(320, 240)

top.pump(&conn.hub)
for {
    e := top.next_event() orelse break
    switch e {
        .configure |cfg| => resize(cfg.width, cfg.height, top.scale)
        .close => running = false
        .output_changed => {}
    }
}
```

A configure with a width or height of zero means that you choose the size. `top.wl_surface` is the surface to attach buffers to. `set_background_blur(compositor, enabled, width, height)` asks the compositor to blur behind a translucent window.

`otter_wayland_render.app_window.Window` goes one step further. `Window.open(env, options)` opens the connection, keyboard, seat and toplevel together and holds them with a renderer and a damage tracker.

| `otter_wayland.video.surface` | A video subsurface for media players, with dma-buf or SHM frames. |

## Outputs

`capture_output.OutputList` is the one place that stores output state: mode, position, transform, name and scale. Give it the output globals as shown above, call `pump` after each dispatch, and read `items()`. `generation` changes whenever an output changes.

`OutputInfo.scale` is the integer `wl_output.scale`, which is a ceiling: 2 on a 150% output. `scale_q8()` is the exact factor in Q8, where 256 is 100%. It is derived from the mode size and the xdg-output logical size, so request `xdg_output_manager` in your interest. A result of `output_scale.unknown_q8`, which is 0, means the scale cannot be known.

## Windows and workspaces

`foreign_toplevel.ForeignToplevelManager`, `toplevel_list.List`, `ext_workspace.ExtWorkspaceManager` and `workspace_provider.WorkspaceProvider` track windows and workspaces. Each has `attach`, `pump` and a generation counter. `toplevel_source` holds the shared rules for listing, focusing and closing windows across the protocols a compositor may offer.

Some state comes from compositor IPC sockets instead of Wayland. Build an `ipc.Endpoints` once with `ipc.Endpoints.from_env(env)` and pass it, with an `std.Io`, to the helpers in `hyprland`, `niri` and `zoolander`.

`zoolander.available(ep)` is true when `XDG_CURRENT_DESKTOP` is `Zoolander`. `zoolander.occupancy(ep, io, names)` asks the compositor's control socket which of up to 32 named workspaces hold windows. It returns one bit per name and gives up after 50 ms.
