`otter-theme` is the visual system every Otter Shell app draws with. A `Theme` has four independent layers: `colors`, `layout`, `spacing` and `globals`. Apps read semantic roles and metrics from it and never branch on a palette or layout name.

The package name is `otter_theme`. Import `otter_theme.theme` for the types and `otter_theme.loader` to load them.

```toml
[dependencies]
otter_theme = { path = "../../otter-theme/otr" }
```

```otr
import std
import std.mem
import otter_theme.loader

pub fn main(env: std.Env) void {
    t := loader.load_theme(env, mem.heap)
    defer t.deinit()

    window := t.surface_color(t.colors.surface)
    std.io.printf("{} {} {}\n", .{ window.to_hex_string()[0..], t.spacing.row_height, t.label_size() })
    std.io.printf("{} at {} px\n", .{ t.globals.font_family.as_str(), t.globals.font_size })
}
```

A `Theme` owns its text fields, so release it with `deinit()`. `clone(alloc)` gives another owner an independent copy.

| Module | Purpose |
| --- | --- |
| `theme` | `Theme`, `Colors`, `Layout`, `Spacing`, `Globals` and the semantic methods |
| `presets` | The 11 built-in color palettes |
| `profiles` | The `current` and `bank` layouts and the three spacing scales |
| `loader` | Read `theme.conf` and its layer files |
| `theme_watcher` | Hot reload for the theme and its layer files |
| `color_contrast` | WCAG relative luminance and contrast ratio |
| `syntax` | Code colors derived from the color roles |

There are 11 color presets. Islands is the `bar_islands` global and works with any of them.

## Lua

The `otter_theme_lua` package in `otr/lua/` exposes `otter.theme` to [otter-lua](/developers/libraries/otter-lua) hosts. Reads need no capability. `use_preset` needs `theme-write`.

```lua
local theme = require("otter.theme")
local host = require("otter.host")

local t = theme.get()
theme.subscribe(function()
  t = theme.get()
  host.redraw()
end)

local accent = theme.color("accent")
local panel = theme.surface(t.colors.surface)
local padding = t.spacing.tiny
```

`subscribe` calls your function after a change that loaded. A broken edit keeps the previous theme and calls nobody.
