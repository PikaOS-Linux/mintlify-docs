Import `otter_theme.theme`. `Theme` holds four sections:

| Section   | Purpose                                             |
| --------- | --------------------------------------------------- |
| `colors`  | Twelve semantic color roles                         |
| `layout`  | Window/chrome geometry and style choices            |
| `spacing` | Shared density and spacing values                   |
| `globals` | Fonts, icons, layer paths, opacity, shared settings |

`Color` is the geometry package's color type. Layout and global text fields use `otter_conf.text.Text`, making the complete theme an owned resource.

## Resolve semantic values

Call methods on a borrowed theme:

- `surface_color`, `panel_color`, `popup_color`, `widget_color`.
- `overlay_color`, `shadow_color`, `highlight_edge`, `clear_color`.
- `bar_background`, `bar_group_background`, `bar_group_border`.
- `dock_background`, `dock_border`.
- `label_size`, `title_size`, `display_size`, `secondary_text_size`.
- Decoration button sizing and padding helpers.

Use these values rather than reproducing opacity or geometry rules in each app. Explicit per-app config overrides still take priority where an app supports them.

## Profiles and density

`otter_theme.profiles.current()` and `bank()` each return a fresh theme resource. `compact`, `standard`, and `spacious` are plain `Spacing` constants.

## Lua snapshot

`otter.theme.get()` returns `{ generation, colors, layout, spacing, globals, tokens }`. Colors are `0xRRGGBBAA`, suitable for SD drawing. `color(role)` validates role names; it is not an arbitrary field lookup.
