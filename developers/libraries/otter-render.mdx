CPU rendering pipeline for all Otter UI.

- ARGB color operations (Wayland argb8888 compatible)
- FreeType font rendering with glyph caching
- HarfBuzz shaping + itijah bidi via `TextSystem` / `ShapeScratch`
- Image loading (PNG, JPG, BMP, GIF via zigimg). Decoded RGBA size is capped separately from compressed file size (up to 256 MiB decoded).
- Sprite sheets and animation (integer-only ease-out quadratic)
- `CommandList` deferred rendering + `quad_renderer` with scissor clipping and damage culling
- `CommandList.graph()`: filled area plus line chart for time-series samples (used by monitor history graphs)
- SDF-based rounded rectangles

### TextSystem

`TextSystem` wraps HarfBuzz and itijah bidi around a `Font`. Use it for RTL text, mixed-direction labels, and CJK. Plain ASCII can stay on the FreeType fast path when you omit `TextSystem`.

- `TextSystem.init(allocator, font)` / `deinit`
- `ShapeScratch`: caller-owned buffer for shaped glyphs and bidi state, reused each frame
- `hasStrongRtlUtf8` / `hasStrongRtlCodepoints`: quick checks before shaping
- RTL glyph order matches HarfBuzz during rasterization

Pass `text_system` and `text_scratch` through `otter-ui` `FrameOptions`, or attach both to `CommandList` for direct rasterization.

```zig
const render = @import("otter_render");

fn drawHello(surface: *render.Surface, font: *render.Font) !void {
    const accent = try render.parseColor("#FF5500");
    surface.clear(render.Color.black);
    font.drawText(surface, "Hello", .{ .x = 0, .y = 20 }, 16, accent);
}
```

Build flag `-Denable_text=false` drops font and shaping support.
