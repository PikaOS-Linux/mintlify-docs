CPU rendering pipeline for all Otter UI.

- ARGB color operations (Wayland argb8888 compatible)
- FreeType font rendering with glyph caching
- HarfBuzz shaping + itijah bidi via `TextSystem` / `ShapeScratch`
- Image loading (PNG, JPG, BMP, GIF via zigimg)
- Sprite sheets and animation (integer-only ease-out quadratic)
- `CommandList` deferred rendering + `quad_renderer` with scissor clipping and damage culling
- SDF-based rounded rectangles

### TextSystem

`TextSystem` wraps HarfBuzz and itijah bidi around an existing `Font`. Use it for RTL paragraphs, mixed-direction labels, and CJK. Simple ASCII can stay on the FreeType fast path when no `TextSystem` is attached.

- `TextSystem.init(allocator, font)` / `deinit`
- `ShapeScratch` holds per-frame shaped glyphs and bidi state (caller-owned, reusable)
- `hasStrongRtlUtf8` / `hasStrongRtlCodepoints` for cheap preflight
- Preserves HarfBuzz RTL glyph order during rasterization

Wire `TextSystem` into `otter-ui` frames via `FrameOptions.text_system` and `FrameOptions.text_scratch`, or pass both into `CommandList` for direct rasterization.

```zig
const render = @import("otter_render");

const color = try render.parseColor("#FF5500");
var surface = render.Surface.fromPixels(&pixels, width, height);
surface.clear(render.Color.black);
font.drawText(&surface, "Hello", .{ .x = 0, .y = 20 }, 16, render.Color.white);
```

Build flag `-Denable_text=false` drops font and shaping support.
