## Geometry module

Import `otter_geo.rect` for these value types:

| Type          | Fields or purpose                                                             |
| ------------- | ----------------------------------------------------------------------------- |
| `Point`       | Signed `x`, `y`; `zero`, `add`, `sub`, `spanning_rect`                        |
| `Rect`        | Signed `x`, `y`; `u16` `width`, `height`                                      |
| `Padding`     | `north`, `south`, `east`, `west`; `zero`, `uniform`, `horizontal`, `vertical` |
| `Circle`      | Circle helpers including `largest_circle`, `bounding_box`, `radius`           |
| `Align`       | `start`, `center`, `end`                                                      |
| `BorderRects` | `top`, `bottom`, `left`, `right` rectangles                                   |

## Rectangle operations

- `contains`, `contains_point`, and local/inclusive variants test bounds. Choose the inclusive form only when you want the far edge included.
- `intersection` returns `?Rect`; `bounding_box` includes both rectangles.
- `remove_padding` returns null if the requested inset does not fit. `add_padding` expands bounds.
- `center` and `align_with` place dimensions inside a rectangle.
- `translate`, `origin`, `dims`, `end_x`, `end_y`, and `lerp` support layout and motion.

## Transforms

Import `otter_geo.transform`. `Transform` is a C-layout 2×2 16.16 matrix with `eql`, `is_identity`, and `compose`. Do not use floating-point layout coordinates to represent it.

## Colors

Import `otter_geo.color`. `Color` uses Wayland ARGB8888 pixel layout by default. `from_rgba` accepts `0xRRGGBBAA`; `from_rgb` accepts `0xRRGGBB`.

`parse` accepts palette names and short or full hex forms. `to_str` and `to_hex_string` return a fixed nine-byte hex representation. `with_alpha`, `composite`, `blend`, and `is_dark` provide value-level operations.

Lua drawing colors use `0xRRGGBBAA`; do not treat the internal ARGB pixel integer as a Lua color.
