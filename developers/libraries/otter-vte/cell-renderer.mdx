## Cell contract

Import `otter_vte.cell_renderer`. `Cell` is a concrete borrowed view containing codepoints, optional RGB colors, width, and `StyleFlags`.

`CellRenderer(App, Sel, hooks)` requires explicit interfaces:

- `App` implements `CellHost`: hovered URL state, blink visibility, text measurement.
- `Sel` implements `SelectionRange.contains`.
- `Hooks` supplies Kitty-placeholder classification and selection behavior.

`DrawContext` receives mutable visual hashes, column count, font size, selection colors, and borrowed output lists. Profiling counters and blink observations return through that context instead of writing arbitrary application fields.

## Snapshot walking

`otter_vte.snapshot.Rows` borrows column slices from a terminal snapshot. `snapshot.walk` gathers graphemes into caller-kept storage, then visits cells through `CellVisitor`.

The terminal app constructs this view from its terminal backend. `otter-vte` renders snapshots; it does not own the PTY or parse terminal escape sequences.

## Layered renderer

`renderer.Renderer.init(alloc)` owns base, background, and text command lists, powerline/block operations, and rounded-mask cache.

Call `prepare`, `configure(Scale)`, then emit cells. Base/background raster helpers accept explicit surfaces and damage. Text is rasterized directly with `quad_renderer.rasterize` and caller-owned text resources.

Keep the snapshot and mutable renderer in separate borrowed arguments during the walk. Do not retain borrowed cell text after visiting it.
