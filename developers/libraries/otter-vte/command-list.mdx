Import `otter_vte.command_list`. `DynamicCommandList.init(alloc)` owns growable command and text lists. Its consuming `deinit()` frees storage.

## Capacity

`ensure_grid_capacity`, `ensure_background_capacity`, and `ensure_text_capacity` prepare storage for the terminal geometry. Appends before initial capacity preparation drop and count commands instead of implicitly growing.

`reset` reuses allocated storage for the next frame. `dropped` reports lost output. Treat nonzero drops as a capacity/verification failure, not an acceptable rendering mode.

## Drawing

Methods include `solid_rect`, `blend_rect`, `rounded_solid_rect`, `rounded_blend_rect`, `rounded_rect_outline`, `clear`, `text`, and `text_styled`. `command_slice` and `get_string` expose recorded output.

`set_scale` takes `otter_render.scale.Scale`; `scale_factor` and `scale_q8` expose exact scale. There are no stored font or text-system pointers.

## Rasterization

Use `otter_render.quad_renderer.rasterize` with a caller-built `TextContext` for text commands and `otter_vte.renderer.no_images` as the image source. `Renderer.rasterize_text` is not part of the otr API.

Keep terminal draw buffers separate from snapshot borrows so the render walk can mutate commands without aliasing the source rows.
