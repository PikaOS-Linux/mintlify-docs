`otter-theme-gen` turns a wallpaper into a color layer in three steps. It hashes the image with SplatHash, decodes seed colors from the hash, and maps the seeds to semantic roles. All three steps live in `otter_tools_core`.

```otr
import std
import otter_tools_core.splathash.decode
import otter_tools_core.splathash.encode
import otter_tools_core.theme_palette

pub fn main() !void {
    // A 2x2 RGBA image. Real callers pass a decoded wallpaper.
    pixels := [16]u8{
        0x1e, 0x66, 0xf5, 0xff, 0x40, 0xa0, 0x2b, 0xff,
        0xdf, 0x8e, 0x1d, 0xff, 0xd2, 0x0f, 0x39, 0xff,
    }
    hash := try encode.encode_rgba(&pixels, 2, 2)
    seeds := decode.extract_seed_colors(&hash)

    palette := theme_palette.generate(.material_you, seeds, .{ mode: .dark, contrast: 0.7, vibrancy: 0.6 })
    primary := palette.primary.to_srgb8()
    surface := palette.surface.to_srgb8()
    std.io.printf("primary #{x:0>2}{x:0>2}{x:0>2}\n", .{ primary[0], primary[1], primary[2] })
    std.io.printf("surface #{x:0>2}{x:0>2}{x:0>2}\n", .{ surface[0], surface[1], surface[2] })
}
```

## SplatHash

The SplatHash modules are `otter_tools_core.splathash.encode`, `decode`, `pack`, `gaussian`, `oklab` and `luts`. Import the one you need.

`encode.encode_rgba(pixels, width, height)` returns the 16-byte hash of an RGBA8 image. It returns `error.InvalidSize` when a dimension is zero or `pixels` is shorter than `width * height * 4` bytes. The encoder samples a 32x32 OKLab grid, so you can pass a downscaled image.

`decode.extract_seed_colors(&hash)` returns a `Seeds` list of up to seven `SeedColor` values in OKLab. The first is the image mean, and the rest add each splat to it.

These modules take pixels and do no image loading. Decode the file with [otter-render](/developers/libraries/otter-render) first.

## Semantic palettes

`theme_palette.generate(strategy, seeds, params)` returns a `roles.SemanticPalette`.

| Argument | Values |
| --- | --- |
| `strategy` | `material_you`, `analogous`, `vibrant`, `monochromatic`, `direct`, `temperature` |
| `params.mode` | `dark` or `light` |
| `params.contrast` | `f32`, 0.7 by default |
| `params.vibrancy` | `f32`, 0.6 by default |

A `SemanticPalette` holds 24 `OklabColor` roles, among them `primary`, `secondary`, `tertiary`, `surface`, `on_surface`, `outline`, `error_color`, `success_color` and `warning_color`. `OklabColor.to_srgb8()` returns the `[3]u8` sRGB value. `hue()` and `chroma()` read a color in OKLab, and `with_lightness(l)` and `with_chroma_scale(f)` return an adjusted one.

Each strategy is also a module, `otter_tools_core.theme_palette.<strategy>`, with its own `generate(seeds, params)`.

A palette supplies colors only. `otter-theme-gen` writes it as a color layer, and the theme's layout and spacing layers stay as they are.

## Lua

`otter_tools_core_lua` has no SplatHash or palette module. A Lua plugin reads the resulting theme through `otter.theme` and switches presets with `otter.theme.use_preset`. See [otter-theme](/developers/libraries/otter-theme#lua).
