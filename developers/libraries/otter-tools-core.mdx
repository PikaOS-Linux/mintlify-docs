`otter-tools-core` shares data processing between small tools and larger applications. Import `otter_tools_core.<module>`; there is no root barrel.

Pure helpers include calculator parsing, durations, calendars, emoji lookup, color conversion, recorder selection, and palette generation. Environment/file/socket operations take explicit `std.Env` or `std.Io`.

Owned results use `String` and `List`; bounded results use standard otr containers. Socket replies append into caller-owned reusable strings rather than returning a 256 KiB inline reply object.

## Separate packages

- `otter_tools_search_engine`: indexing, query parsing, scanning, fuzzy/content search.
- `otter_tools_search`: configured search integration.
- `otter_ocr`: OCR integration.
- `otter_tools_core_lua`: selected `otter.tools.*` modules.

Lua exposure is selective. The weather binding parses bodies and reads caches; it does not fetch forecasts by itself. Search daemon operations require `desktop-search`.
