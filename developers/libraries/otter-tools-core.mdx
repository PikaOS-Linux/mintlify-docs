`otter-tools-core` holds the data processing that the small tools and the larger apps share. The package name is `otter_tools_core`. It has no root module, so you import `otter_tools_core.calc`, `otter_tools_core.weather` and the rest by name.

```toml
[dependencies]
otter_tools_core = { path = "../../otter-tools-core/otr" }
```

```otr
import std
import otter_tools_core.calc
import otter_tools_core.duration

pub fn main() !void {
    std.io.printf("{}\n", .{ try calc.eval("(2+3)*4") })                    // 20
    std.io.printf("{}\n", .{ try duration.parse_seconds("1h1m1s") })        // 3661
}
```

The calculator, durations, calendars, emoji lookup, color conversion, recorder backend choice and palette generation are pure functions. Functions that read the environment, files or sockets take a `std.Env`.

Results that own text are `String` and `List` values you release with `deinit()`. Socket clients append replies to a `String` you pass in, so one buffer serves many requests.

## Nested packages

The repository holds five more packages, each a directory with its own `otr.toml`:

| Package | Directory | Purpose |
| --- | --- | --- |
| `otter_tools_search_engine` | `otr/search_engine/` | File index, query parsing, scanning, fuzzy and content search |
| `otter_tools_search` | `otr/search/` | Search roots and exclusions from the `otter-search` config |
| `otter_ocr` | `otr/ocr/` | Text recognition from a PNG |
| `otter_tools_spell` | `otr/spell/` | Spell checking: dictionaries, tokenizing and the checker |
| `otter_tools_core_lua` | `otr/lua/` | The `otter.tools.*` Lua modules |
