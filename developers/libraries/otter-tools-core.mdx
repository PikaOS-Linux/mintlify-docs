`otter-tools-core` holds shared logic for Otter Shell utility apps. No Wayland, D-Bus, PipeWire, or rendering deps. State stays bounded; each app keeps UI thin.

Config schemas for small apps live in `app_configs.zig` and sync with `otter-settings` defaults.

## Module overview

| Module | Used by |
|--------|---------|
| `calc` | `otter-calc`, `otter-launcher` (`=EXPR`) |
| `emoji` | `otter-emoji`, `otter-launcher` (`:QUERY`) |
| `clipboard` / `clip_history` | `otter-clip`, `otter-launcher` |
| `calendar` | `otter-cal` |
| `duration` | `otter-timer` |
| `weather` | `otter-weather` |
| `color` | `otter-pick` |
| `record` | `otter-rec` encoder selection |

Clipboard helpers invoke `wl-copy` by name. Packaged installs shadow that binary with `otter-copy`.

## Dependencies

`otter-conf`, `otter-utils`.
