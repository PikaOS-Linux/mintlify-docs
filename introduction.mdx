Otter Shell is an otterly fast, resource-light Linux desktop environment built exclusively for Wayland on PikaOS. It is composed of a collection of tightly integrated native applications — each one purpose-built, small, and efficient. From a terminal emulator to a screen recorder, clipboard manager, and on-device speech transcription, everything in Otter Shell is designed to work seamlessly together.

## What's Included

<CardGroup cols={2}>
  <Card title="Otter Terminal" icon="terminal" href="/apps/otter-term">
    A full-featured Wayland terminal emulator with tabs, split panes, shell integration, and URL handling.
  </Card>
  <Card title="Screenshot & Recording" icon="camera" href="/apps/otter-screenshot">
    Capture regions, windows, or the full screen with native Wayland capture — no X11, no grim.
  </Card>
  <Card title="Clipboard Manager" icon="clipboard" href="/apps/otter-clip">
    Persistent clipboard history with search, pinning, image support, and a Super+V popup.
  </Card>
  <Card title="Screen Recorder" icon="video" href="/apps/otter-rec">
    Hardware-accelerated recording via NVENC, Quick Sync, and VAAPI with region and window capture.
  </Card>
  <Card title="Product Shot Composer" icon="image" href="/apps/otter-shot">
    Frame screenshots with gradients, shadows, corner radius, and custom chrome for polished exports.
  </Card>
  <Card title="Speech Transcription" icon="microphone" href="/apps/otter-transcribe">
    On-device hotkey-triggered transcription using an embedded Parakeet model — no cloud required.
  </Card>
  <Card title="Sticky Notes" icon="note-sticky" href="/apps/otter-note">
    Markdown sticky notes on a persistent layer-shell surface, toggled with Super+N.
  </Card>
  <Card title="Weather Widget" icon="cloud-sun" href="/apps/otter-weather">
    Open-Meteo weather fetcher for the bar and a 7-day forecast popup.
  </Card>
</CardGroup>
