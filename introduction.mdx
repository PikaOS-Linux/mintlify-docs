Otter Shell is an otterly fast, resource-light Linux desktop environment built for Wayland on PikaOS. It is a collection of tightly integrated native applications — each purpose-built, small, and efficient — plus shared Zig libraries that power the UI stack.

## Desktop shell

The shell layer runs as background daemons and overlays on top of your Wayland compositor:
