This guide covers the essential first steps after installing Otter Shell. You need a running Wayland compositor session before any Otter app can open windows.

<Steps>
  <Step title="Launch the terminal">
    ```bash
    otter-term
    ```

    Otter Terminal is CPU-rendered via the shared Otter render stack — no GPU dependency for the terminal grid itself.
  </Step>

  <Step title="Start background daemons">
    Several Otter Shell components must run as daemons. Start the essentials now:

    ```bash
    otter-bar &
    otter-wallpaper &
    otter-notifications &
    otter-osd &
    otter-clip daemon &
    otter-idle &
    otter-polkit &
    ```

    For a permanent setup, add these to your compositor autostart. See [Session setup](/desktop/session-setup) for a complete autostart block and compositor-specific examples.
  </Step>

  <Step title="Open the launcher">
    Run the application launcher (bind this to a compositor hotkey for daily use):

    ```bash
    otter-launcher
    ```

    Type to search applications. Try extensions: `=2+3*4` for calculator results, `:heart` for emoji, or `clip` for clipboard history.
  </Step>

  <Step title="Take a screenshot">
    ```bash
    otter-screenshot
    ```

    Click and drag to select a region. The image is copied to your clipboard automatically.
  </Step>

  <Step title="Create a sticky note">
    ```bash
    otter-note new
    ```

    Bind a compositor hotkey to this command for quick access — for example `Super+N`.
  </Step>

  <Step title="Check the weather">
    Print current conditions to stdout:

    ```bash
    otter-weather
    ```

    To show weather on the status bar, configure `otter-bar` with a weather widget and run the cache watcher:

    ```bash
    otter-weather --watch 900 --write-cache &
    ```

    See [otter-weather](/apps/otter-weather) and [otter-bar](/desktop/otter-bar) for widget setup.
  </Step>
</Steps>

<Tip>
  **Bind global hotkeys in your compositor** — Wayland apps cannot grab system-wide shortcuts on their own. Examples:

  **Hyprland** (`~/.config/hypr/hyprland.conf`):

  ```ini
  bind = $mainMod, D, exec, otter-launcher
  bind = $mainMod, P, exec, otter-screenshot
  bind = $mainMod, R, exec, otter-rec
  bind = $mainMod, V, exec, otter-clip popup
  bind = $mainMod, N, exec, otter-note new
  bind = $mainMod, L, exec, loginctl lock-session
  ```

  **Sway** (`~/.config/sway/config`):

  ```
  bindsym $mod+d exec otter-launcher
  bindsym $mod+p exec otter-screenshot
  bindsym $mod+v exec otter-clip popup
  ```

  See [Keybinds](/configuration/keybinds) for a full reference.
</Tip>
