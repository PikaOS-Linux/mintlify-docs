The easiest path is **`otter-settings`**, a graphical editor with a tab per app, a theme browser, and a drag-and-drop bar layout editor. It writes the same `~/.config/otter-shell/*.conf` files you'd edit by hand, so you can switch between GUI and text whenever you want.

```bash
otter-settings
```

Launch it from [otter-launcher](/desktop/otter-launcher), bind a compositor hotkey, or run the command above. See the full [otter-settings](/desktop/otter-settings) reference for tabs, features, and theme presets.

<Note>
  Most settings take effect right after you click **Apply**. Running apps watch their config files via inotify and reload without a restart.
</Note>

## What you can configure in otter-settings

| Tab | What you edit |
|-----|---------------|
| Bar | Widget layout, clock, volume, tray, custom buttons |
| Launcher | Size, colors, placeholder text |
| Notifications | Position, timeouts, margins |
| Wallpaper | Path, rotation, scale mode |
| OSD | Volume/brightness overlay appearance |
| Terminal | Fonts, colors, padding, keybinds |
| Theme | Colors, spacing, presets (12 built-in themes) |
| Lock / Logout / Idle / Polkit / Jade | Session and overlay settings |
| Recorder / Voice | `otter-rec` and `otter-vox` options |

Global compositor hotkeys (screenshot, launcher, lock) are **not** in otter-settings. Bind those in your compositor config. See [Keybinds](/configuration/keybinds).

## File format

```conf
# Comments start with #
font_size = 14
font_family = "IoskeleyMono Nerd Font"
url_enabled = true
```

Quote string values with double quotes. Booleans are `true` or `false`. An empty string `""` falls back to the compiled default.

On first launch, apps normalize their config file. Missing keys get defaults; unknown keys are removed.

## Hot reload

Most daemons watch their config (and often `theme.conf`) with inotify:

- **otter-bar**, **otter-notifications**, **otter-wallpaper**, **otter-osd**, **otter-idle** — reload on save without restart
- **otter-term** — hot-reloads fonts, colors, padding, and scrollback
- **otter-transcribe** — reloads settings and watches `theme.conf`

Changes in otter-settings hit the same hot-reload path as saving the file by hand.

## System-wide defaults

Lookup order (example for `otter-term`):

1. `~/.config/otter-shell/otter-term.conf` *(user — highest priority)*
2. `/etc/otter-shell/otter-term.conf` *(system defaults)*
3. Compiled-in defaults

Administrators can set defaults in `/etc/otter-shell/` without touching home directories.
