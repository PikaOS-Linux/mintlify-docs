Otter Shell apps share a unified visual theme through `otter-theme`. The easiest way to change colors, spacing, and presets is the **Theme** tab in [otter-settings](/desktop/otter-settings) — it includes a live preview of all 12 built-in presets.

```bash
otter-settings
```

Select a preset in the theme browser and click **Apply**. Changes write to `~/.config/otter-shell/theme.conf` and propagate to running apps that watch the theme file.

<Tip>
  Prefer otter-settings over hand-editing `theme.conf` unless you need keys the UI does not expose. The settings app preserves comments and field order when saving.
</Tip>

## Theme config file

Advanced users can edit `~/.config/otter-shell/theme.conf` directly. Apps such as otter-bar, otter-transcribe, and otter-term read this file at startup and re-apply it when it changes on disk.

## Terminal colors

Configure otter-term's 16-color palette and UI chrome in otter-settings under the **Terminal** tab, or edit `~/.config/otter-shell/otter-term.conf`:

```conf
colors_background = "#1e1e2e"
colors_foreground = "#cdd6f4"
colors_cursor     = "#f5e0dc"
colors_selection  = "#313244"

# 16-color palette
colors_black   = "#45475a"
colors_red     = "#f38ba8"
colors_green   = "#a6e3a1"
colors_yellow  = "#f9e2af"
colors_blue    = "#89b4fa"
colors_magenta = "#f5c2e7"
colors_cyan    = "#94e2d5"
colors_white   = "#bac2de"
```

Terminal color changes hot-reload as soon as you save — open terminals update immediately.

## App-level color overrides

Individual apps expose color keys that override the shared theme. For example, in otter-transcribe's **Transcribe** tab (or `otter-transcribe.conf`):

```conf
background_color  = ""
border_color      = ""
graph_color       = ""
graph_peak_color  = ""
text_color        = ""
```

Leave a value as an empty string `""` to inherit from the theme. Set a hex color to override for that app only.

## Font

The default terminal font is `IoskeleyMono Nerd Font`, bundled in `otter-shell-fonts` at `/usr/share/fonts/otter-shell/`.

Change the font in otter-settings under **Terminal**, or in `otter-term.conf`:

```conf
font_family    = "JetBrains Mono"
font_size      = 14
font_dpi_aware = true
```

`font_dpi_aware = true` scales the font and padding on high-DPI displays. An empty `font_family = ""` falls back to the bundled Nerd Font.

## Built-in presets

Available in the otter-settings theme browser:

Otter Shell, Otter Shell Islands, Catppuccin (Mocha/Latte/Frappe/Macchiato), Nord, Gruvbox, Dracula, Tokyo Night, One Dark.
