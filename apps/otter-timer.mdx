otter-timer counts down a duration and pings the desktop through `otter-osd` when available. It always prints `timer done` on completion. You can set a custom notification message or run a shell command when the timer ends.

## Usage

```bash
otter-timer 5m                              # 5 minute timer
otter-timer --message "Tea" 3m              # custom notification message
otter-timer --command 'playerctl pause' 30m # run command on completion
otter-timer --dry-run 30s                   # print timer without running
otter-timer --no-notify 1h                  # skip desktop notification
```

## Duration Format

Durations use `s` (seconds), `m` (minutes), `h` (hours), and `d` (days). Chain segments in any order:

```bash
otter-timer 1h30m
otter-timer 90s
otter-timer 2h45m30s
```

## Configuration

otter-timer reads its settings from `~/.config/otter-shell/otter-timer.conf`:

```conf
default_duration = ""
message = "Timer done"
command = ""
notify = true
```

| Key | Description |
|---|---|
| `default_duration` | Duration to use when none is provided on the command line |
| `message` | Notification message shown when the timer finishes |
| `command` | Shell command to run after the timer completes |
| `notify` | Set to `false` to suppress the desktop notification |

<Tip>
Set `default_duration` to your usual timer length, like `25m` for Pomodoro, so you can run `otter-timer` with no arguments.
</Tip>
