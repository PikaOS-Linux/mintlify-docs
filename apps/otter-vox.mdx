otter-vox turns text into speech on your local machine using an embedded Kokoro TTS model — no internet connection required. Pipe in text, choose a voice from over 50 options, and play the result or save it as a WAV file.

## Usage

Pipe text into otter-vox or pass it as a positional argument. Use `--no-play` to write a WAV stream to stdout, or `-o` to save directly to a file.

```bash
printf 'Welcome to Otter Shell.' | otter-vox --no-play | pw-play -  # pipe to PipeWire
printf 'Welcome to Otter Shell.' | otter-vox -o speech.wav           # save to file
otter-vox --voice bm_lewis --play 'Welcome to Otter Shell.'          # speak with voice
otter-vox --check-model                                               # verify model
otter-vox --list-voices                                               # list all voices
```

## Output Options

otter-vox gives you full control over where the generated audio goes.

- **Default** — plays audio immediately via your system audio output.
- **`--no-play`** — writes a raw WAV stream to stdout so you can pipe it to another program.
- **`-o PATH` / `--output PATH`** — saves audio to a file instead of (or alongside) playing it.
- **`-o speech.wav` with playback enabled** — saves the file and plays it simultaneously.

## Configuration

otter-vox reads its configuration from `~/.config/otter-shell/otter-vox.conf`.

```conf
model_dir = ""
output_path = "-"
playback = true
voice = "bm_george"
cpu_threads = 4
```

Setting `model_dir = ""` uses the embedded model, which is extracted automatically at runtime. Set `model_dir` to a custom directory path to use your own Kokoro model and voice files instead.
