otter-calc is a quick expression evaluator for Otter Shell. Type a math expression on the command line, get the result immediately, and optionally copy it to the clipboard with `--copy`.

## Usage

Pass your expression as a single argument or as multiple arguments — otter-calc joins them automatically before evaluating.

```bash
otter-calc '2 + 3 * 4'          # evaluates to 14
otter-calc 2 + 3 '* 4'          # arguments are joined
otter-calc --copy '(2 + 3) * 4' # evaluate and copy result
```

## Configuration

otter-calc reads its configuration from `~/.config/otter-shell/otter-calc.conf`.

```conf
copy_result = false
```

Set `copy_result = true` to always copy the result to the clipboard without passing `--copy` each time.

<Note>
  `--copy` uses the shared Otter clipboard helper (`otter-copy`). In packaged
  installs, `wl-copy` is shadowed to `otter-copy` so clipboard integration works
  transparently.
</Note>
