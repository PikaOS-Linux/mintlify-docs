`otter-screenshot` is Otter Shell's native Wayland screenshot tool. It captures using the `ext_image_copy_capture_v1` protocol directly — there are no X11 fallbacks, no dependency on `grim`, and no external capture tool involved. By default, drag to select a region and the result is copied to the clipboard as `image/png`. Pass `--output` to write to a file instead.

## Basic Usage

Run `otter-screenshot` without any arguments to enter region-selection mode. Drag with the left mouse button to define the area, or press <kbd>Esc</kbd> / <kbd>Ctrl+C</kbd> before selecting to cancel.

```bash
otter-screenshot                                       # drag to select a region
otter-screenshot --output screenshot.png               # save region to file
otter-screenshot --fullscreen --output screenshot.png  # capture all outputs
otter-screenshot --active --output active.png          # capture active window
otter-screenshot --freeze --output region.png          # freeze before selecting
```

## Options

| Flag | Short | Description |
|---|---|---|
| `--output PATH` | `-o PATH` | Write the PNG to `PATH` instead of copying it to the clipboard. |
| `--fullscreen` | — | Capture all outputs immediately, without opening the selection overlay. |
| `--active` | — | Capture the compositor-reported active toplevel immediately. See [Compositor Requirements](#compositor-requirements) for the necessary protocol support. |
| `--freeze` | — | Capture the screen first, then display that frozen image behind the selection overlay. Useful when the content you want to capture would disappear while you drag. |
| `--cursor` | — | Include the cursor in the captured image. The cursor is hidden by default. |
| `--border` | — | Keep the selection border in the final image. By default the border is only a visual selection aid and is cropped out. |
| `--tonemap-hdr` | — | Apply a simple SDR tonemap before encoding. Use this as a best-effort fallback when capturing HDR outputs — it is not color-managed output. |
| `--help` | `-h` | Print usage and exit. |

## Clipboard

When no `--output` path is given, `otter-screenshot` pipes the PNG through `wl-copy --type image/png`. Otter Shell ships its own `wl-copy` as part of the native data-control implementation, so no additional clipboard utility is needed.

File output writes directly to disk and does not touch the clipboard at all.

## Compositor Requirements

<Warning>
  `otter-screenshot` requires the compositor to expose the `ext_image_copy_capture_v1` protocol for output capture. If the compositor does not support it, the tool exits with an error rather than falling back to another capture path.

  Active-window capture (`--active`) additionally requires both `ext_foreign_toplevel_list_v1` and `ext_foreign_toplevel_image_capture_source_manager_v1`. If either protocol is absent, the `--active` flag will not function.
</Warning>

## Binding a Shortcut

<Tip>
  Bind `otter-screenshot` to a hotkey so you can trigger it instantly from anywhere on the desktop. For example, in a River compositor config you would add:

  ```bash
  riverctl map normal Super S spawn otter-screenshot
  riverctl map normal Super Shift S spawn "otter-screenshot --freeze --output ~/Pictures/screenshot.png"
  ```

  Replace `Super S` with whichever key combination suits your workflow. Consult your compositor's documentation for the equivalent binding syntax.
</Tip>
