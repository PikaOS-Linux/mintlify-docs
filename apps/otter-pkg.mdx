`otter-pkg` is a graphical package manager for Debian-family systems. It talks to apt through the `zapt` API from `apt-dpkg-libs` instead of parsing command output. You can browse, search, and inspect packages without taking the apt lock or asking for a password. Elevation happens only when a system change starts.

## Usage

```bash
otter-pkg
```

Launch from [otter-launcher](/desktop/otter-launcher) or the **Otter Packages** desktop entry.

Search names and descriptions from an in-memory index. Start a query with `?` for apt patterns. You can filter installed, upgradable, automatic, held, broken, and selected packages. Detail views show versions, repositories, dependencies, reverse dependencies, installed files, reasons, and change notes. In-app **Help** covers the UI.

## Changing packages

You can install, update, reinstall, remove, purge, hold, and switch automatic/manual state. Chosen versions are allowed, including downgrades when apt permits them.

Updates can be direct, pull in needed software, or run as a full update that permits removals. There is also unused-package cleanup and interrupted-install repair. **Unmark all** clears every saved selection from the package list or the change summary.

**Check & apply updates** refreshes package lists, then applies updates automatically when no review is needed. Saved selections, held-back packages, hold overrides, removals, downgrades, and essential-package warnings stop at the summary for you to review. Authentication still applies.

Before you authenticate, the change preview lists package, download, disk-space, dependency, held-package, and essential-package effects. Upgrades, downgrades, and removals use distinct colors, with old versions struck through. Recommended additions, held-back updates, and optional add-ons appear in separate review tabs. Switch tabs with the arrow keys. In the **Options** tab you can turn off recommended software; the choice is saved. Optional add-ons and no-longer-needed packages stay separate from required changes. Neither is silently installed or removed.

`pkexec` and polkit run only when a system change begins. After elevation, `otter-pkg` rechecks a cryptographic summary so the approved set cannot silently become a different set.

Live progress shows speed, time remaining, file counts, fetched bytes, and per-package status. Open **Details** for package setup, settings-file choices, and software-source or installation-media questions. You can cancel safely.

Package work holds a logind idle inhibitor and releases it afterward, including failure and cancel paths.

<Note>Package changes need a polkit authentication agent running in your session, such as [otter-polkit](/desktop/otter-polkit). Installing `pkexec` alone does not give you a password dialog.</Note>

## Update tray

`otter-pkg-updates` is a background tray process that starts with your session through the **Otter Package Updates** autostart entry. You can also start it with `otter-pkg --tray`. Click the tray icon to open the package window. Closing the window leaves monitoring active.

The tray checks for available updates every minute without elevation and notifies you when the set of available updates changes. It never prompts for a password.

The `otter-pkg-refresh.timer` systemd timer refreshes repository lists every six hours, with a random delay of up to 15 minutes. It downloads metadata only and never installs updates. To stop periodic refreshes:

```bash
sudo systemctl disable --now otter-pkg-refresh.timer
```

Disable the tray through your desktop's autostart settings.

## Safety

The GUI sends a bounded binary request to its own elevated helper. The helper accepts at most 4,096 package requests, takes the apt lock, resolves everything again, compares the approved SHA-256 summary, checks disk space, and keeps unauthenticated packages disabled. No shell command is assembled from package names. Browsing, detail lookup, local search, saved changes, and history stay unprivileged.

Essential removals require the exact phrase `REMOVE ESSENTIAL` before elevation.

## State files

`$XDG_STATE_HOME/otter-pkg/` (or `~/.local/state/otter-pkg/`) holds:

- `changes`: package choices and update/cleanup options
- `history`: the newest 100 completed or failed operations
