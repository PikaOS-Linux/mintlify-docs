`otter-term` is Otter Shell's built-in terminal emulator. It embeds Ghostty's `ghostty-vt` core in a static `libotter_vt` library. Otter libraries handle Wayland windows, PTYs, input, rendering, configuration, and the clipboard. The terminal supports tabs, horizontal and vertical splits, OSC shell integration, and IME input. It requires neither X11 nor an installed `libghostty-vt` library.

## Launching

Pass a directory path to open there, or use `-e` to run a command instead of your default shell.

```bash
otter-term                                      # open with default shell
otter-term /path/to/project                     # open in directory
otter-term --cwd /path/to/project               # same, with explicit flag
otter-term --working-directory /path/to/project # long form of --cwd
otter-term -e htop                              # run a command
otter-term --execute sh -lc "htop"              # long form of -e
otter-term -- nano file.txt                     # pass arguments to command
otter-term --self-test                          # run the built-in PTY self-test and exit
```

`--cwd` and `--working-directory` also accept the `--cwd=PATH` form.

## Configuration

`otter-term` reads `~/.config/otter-shell/otter-term.conf`, then `/etc/otter-shell/otter-term.conf`, then compiled defaults. On startup it normalizes your file, adding missing defaults and removing unknown keys. The file **hot-reloads whenever you save it**. Font, colors, padding, and grid size update without restarting the terminal. The **Terminal** tab in otter-settings edits the same keys.

Terminal chrome (tab strip, split rules, status pills, visual bell) follows `theme.conf` and its profile, and hot-reloads when you save it.

```conf
general_shell = ""
general_term = "xterm-256color"
general_width = 900
general_height = 560
general_scrollback_rows = 10000
general_allow_clipboard_write = true
general_clipboard_write_max_bytes = 1048576

font_family = "IoskeleyMono Nerd Font"
font_path = ""
font_fallback_path = "/usr/share/fonts/otter-shell/IoskeleyMonoNerdFont-Regular.ttf"
font_size = 14
font_dpi_aware = true
font_scale_percent = 100
font_cell_height = 0
font_baseline_offset = 0

padding_x = 4
padding_y = 4

keybinds_copy = "ctrl+shift+c"
keybinds_paste = "ctrl+shift+v"

url_enabled = true
url_underline = true
url_highlight_on_hover = true
url_open_command = "xdg-open"

scroll_fixed_per_row = 10
scroll_rows_per_notch = 3

shell_capture_output = false

bell_enabled = true
bell_command = "paplay /usr/share/sounds/freedesktop/stereo/bell.oga"
bell_visual = false
```

<Note>`general_shell = ""` uses `$SHELL`, falling back to `/bin/sh` if unset. The default `general_term` value `xterm-256color` works best for remote hosts over SSH. Only set it to `xterm-ghostty` when the target host has that terminfo entry installed.</Note>

<Tip>Set `shell_capture_output = true` to enable OSC 133 command-output capture. The right-click context menu then gets a **Copy Last Output** action that copies the full output of the most recent command. Off by default to keep large command output off the hot PTY path.</Tip>

<Note>`general_allow_clipboard_write` controls OSC 52 and iTerm2 clipboard writes from programs. Writes larger than `general_clipboard_write_max_bytes` are rejected.</Note>

## Color palette

Cell colors come from `colors_*` keys in `otter-term.conf`: `foreground`, `background`, `cursor`, `selection_background`, `url_foreground`, and the 16 ANSI colors (`black` through `bright_white`). Defaults give a complete palette. Palette changes hot-reload on save.

Theme profiles do not change the terminal palette. When generated colors are enabled, [otter-theme-gen](/desktop/otter-theme-gen) supplies the terminal colors through its `otter_term` template.

## Keyboard shortcuts

| Action                                     | Shortcut                                                 |
| ------------------------------------------ | -------------------------------------------------------- |
| Copy selection                             | <kbd>Ctrl+Shift+C</kbd>                                  |
| Paste                                      | <kbd>Ctrl+Shift+V</kbd>                                  |
| New tab                                    | <kbd>Ctrl+Shift+T</kbd>                                  |
| Close tab or split (quits on the last one) | <kbd>Ctrl+Shift+W</kbd>                                  |
| Split pane                                 | Right-click → **Split Horizontal** or **Split Vertical** |

Change the copy and paste shortcuts with `keybinds_copy` and `keybinds_paste`. The right-click menu also has **Copy URL**, **Copy Path**, **Copy Last Output**, **Close Tab/Split**, **Clear**, **Clear Scrollback**, and **Reset**.
