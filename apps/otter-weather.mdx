otter-weather fetches current weather conditions and a 7-day forecast from Open-Meteo and feeds the bar weather widget or opens a popup. Configure your latitude and longitude, run it as a watch daemon, and get live weather on your desktop.

## Usage

Run `otter-weather` without arguments to fetch and print a forecast for the configured location, or pass coordinates directly to override the config.

```bash
otter-weather                             # fetch and print (default: London)
otter-weather 40.7128 -74.0060            # specify coordinates (New York)
otter-weather --dry-run 51.5072 -0.1276   # print Open-Meteo URL without fetching
otter-weather --write-cache               # refresh bar widget cache
otter-weather --watch 900 --write-cache   # refresh every 900 seconds
otter-weather --cache                     # print cached forecast without HTTP
otter-weather --layer                     # open 7-day popup from cache
```

## Bar Widget Integration

The otter-bar weather widget reads from a bounded local cache file. Use `--write-cache` to refresh that cache after a fetch, and combine it with `--watch SECONDS` to keep it updated automatically in the background. Add the following line to your compositor autostart to keep weather data fresh:

```bash
otter-weather --watch 900 --write-cache &
```

The `--layer` flag opens the cached forecast in a small layer-shell popup that closes when clicked — useful for binding to the bar widget button.

<Note>
  Responses are capped at 128 KiB, keeping the cache file small and fetch time
  predictable regardless of network conditions.
</Note>

## Configuration

otter-weather reads its configuration from `~/.config/otter-shell/otter-weather.conf`.

```conf
latitude = 51.5072
longitude = -0.1276
# Optional; empty uses $XDG_CACHE_HOME/otter-shell/weather-cache
cache_path = ""
write_cache = false
watch_seconds = 0
```

The default location is London. Set `latitude` and `longitude` to your city's coordinates to get a local forecast. Leave `cache_path` empty to use the default XDG cache location. Note that `--watch` mode reloads this config file between each refresh, so you can change your location without restarting the daemon.

<Tip>
  Find your coordinates at [Open-Meteo's geocoding API](https://open-meteo.com/en/docs/geocoding-api) or use a site like [latlong.net](https://www.latlong.net).
</Tip>
